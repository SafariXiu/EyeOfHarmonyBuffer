## 🌀 模组简介

**EyeOfHarmonyBuffer** 是一个为「数值即机制」而生的强化向模组。
主打特点：**力大砖飞、大脑清空**（~~维神饼干~~），让你在高压机械与爆炸数值中获得前所未有的爽感。

本模组通过高度可配置的方式，对游戏中的各类机制进行**增强、删改、重构与扩展**，适合想要进一步压榨机械潜力、加速进度、或追求极限数值体验的玩家与服务器。

---

## ✨ 主要特性

本模组提供大量可配置、可自定义的功能，包括但不限于：

1. **机器增强**
   - 为原有机器提供大幅数值提升与机制强化
   - 可通过配置精细调节增强幅度

2. **机制修改 / 删除**
   - 移除或调整部分影响体验的原版 / MOD 机制
   - 用更简单粗暴的方式达到你想要的目标

3. **配方增强**
   - 强化现有配方效率
   - 降低流程复杂度或资源压力

4. **新增单步配方**
   - 为复杂工艺链添加**一键到位**的单步配方
   - 适合后期或服务器高负载环境使用

5. **多方块机器（豪堪风味）**
   - 搭配多方块结构，解锁更强力的机械能力
   - 目前多方块相关功能部分基于他模多方块框架支持

6. **联动增强（私货专区）**
   - 对部分模组进行定制级强化，包括但不限于：
     - `Twist-Space-Technology-Mod`（如：闪电尖塔等）
     - `123tech` 中部分机器与机制
   - 若你有自己的模组想要增强，欢迎在 Issue 中提出需求！

## ⚙️ 配置与自定义

**核心思想：几乎所有数值与机制都可以配置。**

你可以在配置文件中找到：

- 机器性能倍率（速度、能耗、产出等）
- 各类机制开关与行为调整
- 配方倍率与替代单步配方
- 多方块结构与行为相关配置
- 各种 Mixin 功能的启用 / 禁用项

> **提示：**
> 模组的详细功能说明、各项增强的具体参数与说明，请以 **MOD 配置文件** 中的注释与字段为准。

## 🗺️ 世界生成/地形导出（Talos2）指令贴士

> 用于将 Talos2 的大陆噪声/陆海分布等信息导出为图片（通常为 PNG）。
> 导出过程会占用 CPU，建议在服务器空闲时使用。

### 指令格式

```text
/talos2export <distZone|isLand|c01> <sizeBlocks> <stepBlocks> <fileName> [coastRadius] [visRadius]
```

### 参数说明

- `<distZone|isLand|c01>`：导出模式
- `c01`：导出大陆噪声 `c01` 灰度图
- `isLand`：导出陆地/海洋二值图
- `distZone`：导出“近岸/远海”等分区可视化（含可视化半径参数）
- `<sizeBlocks>`：导出覆盖范围边长（单位：方块）
- `<stepBlocks>`：采样步长（单位：方块），越大越快但越糙
- `<fileName>`：输出文件名（建议只写英文/数字/下划线，不要带路径）
- `[coastRadius]`：海岸缓存/距离计算半径（单位：方块，默认 `192`）
- `[visRadius]`：仅 `distZone` 使用的可视化半径（默认 `160`）

### 使用示例（推荐从小图开始）

```text
# 快速验证（小范围）
/talos2export c01 2048 8 test_c01

# 导出 20k 范围的 c01 灰度图
/talos2export c01 20000 8 talos_c01_20k_s8

# 导出陆海分布图（可选传入 coastRadius）
/talos2export isLand 20000 8 talos_island_20k_s8 192

# 导出分区图（distZone 才需要 visRadius）
/talos2export distZone 20000 8 talos_dist_20k_s8 192 160
```

### 注意事项

- 需要 **OP/管理员权限** 才能执行（权限等级 2）。
- 指令在你**当前所在的维度/世界**执行；如果不在 Talos2 维度，可能会提示不可用。
- 导出会在后台线程运行，但仍可能造成卡顿；`sizeBlocks` 越大、`stepBlocks` 越小越吃性能。
- 输出位置取决于导出器实现；一般在**世界存档目录**下的某个导出文件夹（可在控制台日志中查找 “Export path” 或 “finished” 提示）。
