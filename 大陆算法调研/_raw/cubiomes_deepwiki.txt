 Biome Noise System

 The Biome Noise System implements modern noise-based biome generation introduced in Minecraft 1.18, replacing the earlier layer-based approach with a sophisticated multi-dimensional climate parameter system. This system generates biomes using six climate parameters (temperature, humidity, continentalness, erosion, depth, and weirdness) that are sampled from layered Perlin noise and mapped to biomes through decision trees.

 For information about the legacy layer-based biome generation used in MC 1.0-1.17, see Layer System . For structure finding and biome location functionality, see Finders System .

 Overview 

 The noise-based approach represents a fundamental shift from discrete layer processing to continuous multi-dimensional climate sampling. Instead of applying sequential transformations through 44 layers, the system samples six independent climate parameters at each coordinate and uses these to determine the appropriate biome through mathematical splines and decision trees.

 Sources: biomenoise.h 129-137 biomenoise.c 1141-1191 

 Core Noise Components 

 The biome noise system builds upon three fundamental noise primitives that provide the mathematical foundation for all climate parameter generation.

 Perlin Noise Foundation 

 The PerlinNoise structure noise.h 7-16 contains a permutation table for gradient selection and random coordinate offsets. OctaveNoise noise.h 18-22 combines multiple Perlin noise instances at different frequencies, while DoublePerlinNoise noise.h 24-29 samples two octave noise instances with slightly different frequencies to create more complex patterns.

 Sources: noise.h 7-29 noise.c 49-107 noise.c 333-446 

 Climate Parameter Generation 

 Each climate parameter uses DoublePerlinNoise with specific amplitude configurations and frequency ranges. The initialization occurs in init_climate_seed() biomenoise.c 844-907 with hardcoded MD5 hashes for deterministic parameter separation.

 Spline System for Depth Calculation 

 The depth parameter ( NP_DEPTH ) is not directly sampled from noise but calculated using a complex spline system that models terrain elevation based on continentalness, erosion, and weirdness values.

 The spline system uses recursive evaluation where each spline point can reference other splines, creating a hierarchical calculation. The main spline references parameter types: SP_CONTINENTALNESS (0), SP_EROSION (1), SP_RIDGES (2), and SP_WEIRDNESS (3) biomenoise.c 944 

 Sources: biomenoise.h 96-115 biomenoise.c 946-1137 

 BiomeTree Climate-to-Biome Mapping 

 The final step maps the six climate parameters to biome IDs using decision trees that differ by Minecraft version. Each tree node contains parameter ranges and child references.

 The tree search algorithm in get_resulting_node() biomenoise.c 1387-1431 performs a breadth-first search with distance-based pruning, evaluating multiple candidate nodes within the specified search order to find the closest climate match.
