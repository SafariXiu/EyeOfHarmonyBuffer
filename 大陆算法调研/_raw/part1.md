## 0. 与本项目硬约束的对应关系（先读这一节）

| 项目硬约束 | 本类算法给出的答案 |
|---|---|
| O(1) 运行时求值 | 噪声族天然满足。唯一的 O(1) 陷阱是：**不要用需要邻域的算法**（如坡度依赖、河流流量累积、侵蚀迭代），这些是 O(N) 或 O(N²) |
| 块级 16x16 精度 | 只要把采样频率的**最高倍频的波长 ≥ 32 格**，块内单点采样即可。MC 1.18 用 cell_height=8 的 3D 密度插值来绕过这一点 |
| X 无限非周期 | 所有噪声天然满足。但要注意 **float/double 精度**：MC 在 |X| > 2^25 左右开始出现"远地"走样；本项目 X 无限必须限制采样坐标的绝对量级（见附录 B） |
| Z 周期 20,000,000 | 见**附录 B**：整数晶格取模是最省的做法；fbm 的 lacunarity 必须是周期的整数倍关系 |
| 零预计算 | **Non-periodic Tiling（条目 25）**、**Random-access 噪声（条目 11/13）**、样条查表（条目 1）都是纯 O(1)，可直接搬 |
| 双峰高程分布 | 核心配方是**样条重映射**（条目 1 的 continentalness spline），不是单纯 fbm。见附录 A |
| 内海数 = 0、无散落小岛 | 需要**低频大陆掩码 + 形态学约束**。纯噪声做不到。见附录 A 的"大陆掩码"与条目 27 |

**一句话结论**：本类中真正能同时满足"双峰高程 + 大陆架/大陆坡 + 无内海"的，只有**「连续噪声 → 单调样条重映射」**这一条路线（MC 1.18 的 continentalness spline 是它的工业级实现）。其余所有噪声技巧（域弯曲、ridged、cellular、Wang tile）都是这条主线上的**装饰层**，负责海岸线分形维数与山脉细节。
