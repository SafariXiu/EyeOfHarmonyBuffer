### 0.2 全部条目的共同盲区（先说清楚，省得逐条重复）

行星科学与气候文献**几乎不研究**下列三件事：

1. **"内海数 = 0"**：没有文献把"内部封闭海域个数"当指标。最接近的是大陆数量与连通性统计（Cogley 1984，A11）、内流盆地分布、超大陆-裂解旋回（Merdith 2017，A21）。**结论：这条只能靠我们自己的拓扑判据实现，文献只提供"单块大陆是合法地球态"的论据。**
2. **"无散落小岛"**：同样无直接文献。只能借"陆壳/洋壳是两种材质、厚度差 ~4.5 km"这一物理事实从成因上排除小岛。
3. **运行时 O(1) / Java / Minecraft 块级**：全部文献都没有。所有"实时性"字段是按算法结构**推断**的，凡推断处写"（推断）"。

### 0.3 十条最硬的结论（先给实现者）

1. **双峰是物理必然**：陆壳（35-40 km 厚、密度 2.7-2.8）浮在洋壳（6-7 km、2.9-3.0）上，均衡后天然给出**约 +0.1~+0.3 km 的大陆台地**与**约 -4~-5 km 的深海盆地**两个峰。生成器的核心不是"造山"，而是**造两个台地 + 一条窄过渡带**。见 A2 / A4 / A7。
2. **双峰分布 = 一次直方图变换**：把任意噪声 n∈[0,1] 通过"目标双峰分布的逆 CDF"映射，就得到双峰高程，代价是一次一维插值，**O(1)，与纯噪声同级**。见 A2。
3. **海岸线分形维数的闭式控制**：自仿射地形（Hurst 指数 H）的**等值线（海岸线）维数 D = 2 - H**。要 D ~ 1.2-1.4，只需 **H ~ 0.6-0.8**。这是全篇性价比最高的一条。见 A15 / A17 / A18。
4. **单一 fBm 无法同时满足"海岸线维数"与"小尺度粗糙度"**：地球地形功率谱是分频段的近似幂律（A14），深海丘陵另有统计（A9）。必须**分区/分频段**设 H，或两层叠加（低频控大陆、高频控纹理）。
5. **深海台地来自洋底深度-年龄曲线**：d(t) ~ 2500 m + 350*sqrt(t)（t 单位 Ma），约 70-100 Ma 后趋平（板块模型）。只需一个"洋壳年龄"标量场即可 O(1) 生成 -2.5 -> -4.5 km 的深海台地。见 A8。
6. **陆架/陆坡/陆隆坡度差两个数量级**：陆架 ~0.1 度，陆坡 ~3-6 度，陆隆 <0.5 度（Harris 2014 全球海洋地貌省统计）。大陆边缘必须写成**三段分段函数**，不能一个 smoothstep 糊过去。见 A10。
7. **山脉坡度有物理上限**：临界楔体理论给出造山带/增生楔地表坡度 ~2-8 度。山脉高度上限 = 坡度 x 宽度，可防"无限高的山"。见 A25。
8. **陆地占比可由水量 + 双峰高程反解**：把高程分布写成"陆壳峰 + 洋壳峰"两段，水量守恒给出海平面解析关系。给定目标陆地占比，离线解一次得到海平面偏移这一个标量，运行时仍 O(1)。见 A2 / A3。
9. **"陆地占比对气候影响不大"有文献支撑**：Abbot/Cowan/Ciesla 2012 的结论是风化行为与宜居带对表面陆地分数**不敏感**。给了我们"为地貌好看而自由标定陆地占比"的正当性（但温度带布局仍受大陆构型影响，见 B12 / B13）。见 B8。
10. **气候模型的"大陆构型实验"是现成设计空间**：PlaSim green planet / desert world、TRACMIP 理想大陆、ROCKE-3D / ExoPlaSim 陆地分布实验，本质都在问"给定大陆长什么样，气候怎样"。对我们的价值是**反问题**：先定气候带目标，再定大陆形状。见 B1-B13。

## A. 地球高程的双峰分布、成因，与海岸线/洋底的分形统计

### A1. ETOPO 全球地形/水深模型（NOAA NCEI）—— 双峰分布的实测基线

- **1 名称 + 链接**：ETOPO Global Relief Model（ETOPO1 / ETOPO 2022），NOAA National Centers for Environmental Information — https://www.ncei.noaa.gov/products/etopo-global-relief-model （ETOPO1 元数据页：https://www.ncei.noaa.gov/access/metadata/landing-page/bin/iso?id=gov.noaa.ngdc.mgg.dem:316 ）
- **2 一句话原理**：把全球陆地高程与海洋水深合成统一栅格，直接给出"高程-面积"累积曲线（hypsographic curve），其形状就是著名的**双峰 + 双台地**曲线。
- **3 类别**：实测数据集 / 地球科学基础设施
- **4 输出范围**：有限全球栅格（1 弧分 ~ 1.8 km；15 弧秒 ~ 450 m）。**有限地图**，非无限程序化。
- **5 实时性**：完全不实时，只能离线统计。搬入等级【离线标定后搬】（产物是约 8 个浮点数：两峰位、两峰宽、过渡带宽、陆架台阶位置等）
- **6 双峰高程**：有，且是**定义级数据源**。常用量级（约值，落地前请以 ETOPO 原始数据复算）：陆地约占 29.2%，陆地平均高程约 +0.8 km，海洋平均深度约 -3.7 km；大陆台地峰约 +0.1~+0.3 km，深海盆地峰约 -4~-5 km，中间在 -0.2~-1 km（陆坡）处面积密度极低。
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：全部可从数据中提取（陆架台阶、陆坡、海沟负异常、洋中脊正异常都清晰）。
- **8 内海与孤岛**：数据里有（黑海、里海、地中海；大量小岛），但该数据集**不处理**"如何消除它们"。
- **9 语言/依赖/许可证/star**：数据产品，公有领域（美国联邦政府作品）；netCDF/GeoTIFF；无 star 概念。
- **10 对本项目的可借鉴点（可写代码）**：
  1. **离线只做一件事**：从 ETOPO 统计全球高程的累积面积分布 F(h)，取逆 h = F_inv(u)（u 为均匀噪声）。运行时把噪声 u 过这个逆函数，就得到"地球上随便取一点会得到的高程"。这是**分布匹配（histogram matching）**，比"用 fBm 直接当高度"正确得多，且**代价 = 一次一维插值，与纯噪声同级**。
  2. 实现成 **16-32 段分段线性 LUT 常量数组**，硬编码在 Java 源码里（不是外部文件），完全满足"零预计算、零全局缓存"。
  3. 只取分布形状，**不要**取空间相关性——ETOPO 的陆地是真实板块拼出来的，直接采它的空间结构会破坏"X 无限非周期"。
  4. 用 ETOPO 复算三个回归测试基准：陆地占比、双峰峰位、**海岸线分形维数 D**（在 ETOPO 海陆二值图上跑盒计数法），作为我们 D 目标的对照。

### A2. Cowan & Abbot (2014)：把行星高程写成两个 delta 函数，反解海平面

- **1 名称 + 链接**：N. B. Cowan & D. S. Abbot, *Water Cycling Between Ocean and Mantle: Super-Earths Need Not Be Waterworlds*, ApJ 781:27 (2014) — https://doi.org/10.1088/0004-637X/781/1/27 ｜免费预印本 https://arxiv.org/abs/1401.0720
- **2 一句话原理**：把行星高程分布理想化为**两个 delta 函数**（一个在洋壳深度、一个在陆壳高度），再用总水量守恒解出海平面，得到"水量 <-> 洋深 <-> 陆地占比"的解析关系。
- **3 类别**：解析理论 / 行星科学（exoplanet hypsometry）
- **4 输出范围**：解析式，无地图（但可作用到任意地图上）
- **5 实时性**：闭式解；**离线解一次即可**，运行时只需一个常数（海平面偏移）。搬入等级【离线标定后搬】
- **6 双峰高程**：有，**本条就是"双峰模型"的教科书来源**，作者显式用两个 delta 函数代表洋壳与陆壳两个峰。
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无（两个 delta 之间没有过渡带）
- **8 内海与孤岛**：不涉及（模型里只有"陆地"和"海洋"两类面元）
- **9 语言/依赖/许可证/star**：论文（ApJ 付费，arXiv 免费）；无代码仓库要求。
- **10 对本项目的可借鉴点（可写代码）**：
  1. **直接用的反解流程**：设陆壳面积分数 f_land、陆壳峰高 h_c、洋壳峰深 -d_o、海水总量（以"等效全球水深" V_w 表示）。水量全铺在 (1-f) 的洋面上，平均洋深 = V_w/(1-f)。于是可写一个**一维二分求根**（20 次足够）：输入"目标陆地占比"，输出"海平面相对双峰的位置"。
  2. **把它做成离线标定**：目标陆地占比 0.29（地球）-> 离线求根 -> 得到常数 SEA_LEVEL_OFFSET，硬编码；运行时零成本。
  3. **给"陆地占比可标定"一个物理正确的旋钮**：调**海平面高度**，不要调噪声阈值。调阈值会改变海岸线的分形维数，调海平面不会——这是极重要的实现细节。
  4. 把两个 delta 换成"两个窄的高斯/矩形台地"（宽 0.1-0.3 km 与 0.5-1 km），才能在有限分辨率下画出真正像地球的双峰直方图；纯 delta 在块级分辨率下会退化成尖峰。
  5. 配合 A3（https://doi.org/10.3847/0004-637X/832/1/54 ）给出的洋深合法区间，防止标定跑到非物理区间。

### A3. Komacek & Abbot (2016)：水量交换如何改变洋深（双峰模型的参数约束）

- **1 名称 + 链接**：T. D. Komacek & D. S. Abbot, *Effect of Surface-Mantle Water Exchange Parameterizations on Exoplanet Ocean Depths*, ApJ 832:54 (2016) — https://doi.org/10.3847/0004-637X/832/1/54
- **2 一句话原理**：在 A2 的双 delta 高程模型里加入"水在地幔与海洋间往返"的参数化，看洋深（即水量）随时间如何变化；结论是洋深对该参数化敏感。
- **3 类别**：解析/半解析理论，行星科学
- **4 输出范围**：解析式 + 时间演化曲线，无地图
- **5 实时性**：不适用（纯标定用）。搬入等级【离线标定后搬】
- **6 双峰高程**：有，沿用双 delta 模型
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无
- **8 内海与孤岛**：不涉及
- **9 语言/依赖/许可证/star**：论文（ApJ 付费，arXiv 有预印本）
- **10 对本项目的可借鉴点**：
  1. 它给的是**参数合法性区间**：洋深 -3~-5 km 是物理上可长期维持的，而 -10 km 或陆地占比 60% 需要极端假设。用这个给陆地占比标定设上下限（建议 20%-35%）。
  2. 若做"多世界/多种子"，可把**陆地占比当作唯一的行星级随机量**（在 0.20-0.35 采样），其余参数固定——每个种子的世界仍像地球，但海陆比不同。这正是该文的"参数化行星多样性"思路。
  3. 无需搬代码，只借结论。

### A4. Flament, Coltice & Rey (2008)：大陆涌现（continental emergence）与 hypsometry 的耦合模型

- **1 名称 + 链接**：N. Flament, N. Coltice, P. F. Rey, *A case for late-Archaean continental emergence from thermal evolution models and hypsometry*, EPSL 275 (2008) 326-336 — https://doi.org/10.1016/j.epsl.2008.08.029
- **2 一句话原理**：地幔热演化 -> 洋壳厚度与洋中脊深度随时间变化 -> 把洋壳深度分布与陆壳高度分布叠加算海水容量 -> 得出"大陆何时才露出海面"。
- **3 类别**：数值模型（地幔热演化 + hypsometry 解析合成）/ 行星科学
- **4 输出范围**：全局时间序列曲线（涌现面积 vs 时间），无地图
- **5 实时性**：需离线积分（1D 热演化，秒级）。搬入等级【离线标定后搬】
- **6 双峰高程**：有，显式构造陆壳/洋壳两套高程分布并叠加，是"双峰如何随物理参数漂移"的定量研究。
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：部分——**洋中脊深度随洋壳厚度变化**被显式建模（洋脊深度 = f(洋壳厚度) + 均衡），其余不含。
- **8 内海与孤岛**：无（用面积分布，不看拓扑）
- **9 语言/依赖/许可证/star**：论文（EPSL 付费）
- **10 对本项目的可借鉴点**：
  1. **洋脊深度不是自由参数**：它是洋壳厚度与均衡的函数。生成器里洋中脊顶面高度应由"洋壳厚度场"导出，不要手填。
  2. **海水总量固定、陆地面积被解出来**：反向用于海平面调节——先把地形（含洋中脊起伏）全部生成好，再解海平面使陆地占比命中目标。运行时仍是 O(1)，因为海平面是常数。
  3. **涌现面积曲线（陆地占比 vs 洋壳厚度）**可直接当标定曲线：离线算出"洋壳比现在厚 1 km 时陆地占比掉到多少"，就知道参数往哪边调。
  4. 该文"两个分布叠加"的数学形式（洋壳深度用半空间冷却 + 洋脊，陆壳高度用高斯）可以**逐字照抄成 Java 里的两个解析函数**，用于离线拟合目标直方图。

### A5. Tang & Chen (2024, Science Advances)：下地壳致密化如何抑制地形与陆壳出露

- **1 名称 + 链接**：M. Tang, K. Chen et al., *Subaerial crust emergence hindered by phase-driven lower crust densification on early Earth*, Science Advances (2024) — https://doi.org/10.1126/sciadv.adq1952
- **2 一句话原理**：早期地球下地壳发生相变致密化，使地壳整体下沉、地形起伏被压制，于是陆壳难以露出海面——即"地形振幅"本身可由岩石学调节。
- **3 类别**：数值/岩石物理建模 + 地质证据
- **4 输出范围**：1D/2D 岩石学-均衡模型，无全球地图
- **5 实时性**：不适用（离线）。搬入等级【只借思想】
- **6 双峰高程**：有，讨论的正是"两个峰能否分开、陆壳峰能否露出水面"
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无
- **8 内海与孤岛**：不涉及
- **9 语言/依赖/许可证/star**：论文（Science Advances 开放获取）
- **10 对本项目的可借鉴点**：
  1. **"地形振幅"应是显式可调参数**，而不是被噪声幅度隐含决定。双峰间距（陆地台地 vs 深海盆地）就是振幅，给一个常量 CRUST_AMPLITUDE，其地球值约 4.5 km。
  2. 提供"**地球式双峰是长期稳定态**"的论据：今天有双峰，是因为下地壳未大范围致密化。默认用"现代地球"参数即可。
  3. 若将来做"不同地质时代的同类世界"，这条给出切换开关的物理含义（下地壳密度 -> 振幅 -> 陆地占比）。

### A6. McLennan & Taylor (1983)：大陆干舷（continental freeboard）与陆壳体积

- **1 名称 + 链接**：S. M. McLennan & S. R. Taylor, *Continental freeboard, sedimentation rates and growth of continental crust*, Nature 306 (1983) 169 — https://doi.org/10.1038/306169a0
- **2 一句话原理**：大陆相对海平面的"干舷"（露出高度）在大范围地质时间里近似不变，这约束了陆壳体积增长、海水体积与沉积物再分配之间的关系。
- **3 类别**：地球化学/质量平衡理论
- **4 输出范围**：解析质量平衡，无地图
- **5 实时性**：不适用。搬入等级【只借思想】
- **6 双峰高程**：间接有——"干舷不变"意味着陆壳峰相对海平面的位置长期稳定。
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无
- **8 内海与孤岛**：无
- **9 语言/依赖/许可证/star**：论文（Nature 付费）
- **10 对本项目的可借鉴点**：
  1. **"海平面切在双峰之间哪个位置"有地球学约束**：地球海平面把约 29% 面积切在陆壳峰附近、71% 切在洋壳峰附近，且长期稳定。默认标定目标直接取 **29% / 71%**，是最"地球"的选择。

### A8. Parsons & Sclater (1977)：洋底深度-年龄曲线（深海台地的来源）

- **1 名称 + 链接**：B. Parsons & J. G. Sclater, *An analysis of the variation of ocean floor bathymetry and heat flow with age*, JGR 82 (1977) 803-827 — https://doi.org/10.1029/JB082i005p00803
- **2 一句话原理**：洋底随年龄冷却收缩，深度按 d(t) ~ 2500 m + 350*sqrt(t)（t 单位 Ma）下沉，约 70-100 Ma 后偏离 sqrt(t) 律、趋于平台（板块模型）。这就是深海盆地那个"平底"的物理来源。
- **3 类别**：观测 + 解析模型（半空间冷却 / 板块模型）/ 海洋地球物理
- **4 输出范围**：一维曲线（深度 vs 年龄），可作用到任意无限地图
- **5 实时性**：**O(1) 闭式**，只需一个标量（年龄或离洋脊距离）。搬入等级【直接搬】
- **6 双峰高程**：有，深海盆地那个峰（-4~-5 km）**就是这条曲线的平坦段**。没有它，深海会是一个连续倾斜面而不是台地。
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：有洋中脊（t=0 处约 -2.5 km）与深海平原（t 大时约 -4~-5 km）；无陆架/陆坡/岛弧/海沟。
- **8 内海与孤岛**：不涉及
- **9 语言/依赖/许可证/star**：论文（JGR，1977，多处可免费获取）
- **10 对本项目的可借鉴点（可写代码，优先级最高之一）**：
  1. 可直接写进 Java 的公式（常数取自该文拟合，落地前请核对原文表格；下面是可直接调参的结构）：
     ```java
     // t 单位 Ma；返回海平面以下的深度（m，负值）
     static double oceanDepth(double t) {
         double halfSpace = 2500.0 + 350.0 * Math.sqrt(t);            // 半空间冷却
         double plate     = 6400.0 - 3200.0 * Math.exp(-t / 62.8);    // 板块模型，趋近约 -6400 m
         return -Math.min(halfSpace, plate);                          // 取浅者，自动在约 70 Ma 收敛
     }
     ```
  2. **本项目需要一个"洋壳年龄场" a(x,z)**：最简做法是把洋中脊画成若干程序化曲线（可由低频噪声提脊线，或用"离最近脊线的距离 / 半扩张速率"换算），年龄 = 距离 / 半扩张速率。若脊线是解析曲线则 O(1)；若是少量脊段列表，O(log n)，n 很小，块级可接受。
  3. **深海台地 = sqrt(t) 曲线的平坦段**：只要年龄场大部分 > 80 Ma，深海自然形成平底，双峰直方图的右峰自动出现，**不需要额外的"盆地压平"后处理**。
  4. 洋中脊的**高度**由 A4 的洋壳厚度修正，不要硬编码 2500 m。
  5. 若不想维护脊线列表，退化方案：用低频 fBm 场 f∈[0,1] 映射成等效年龄 t = T_max * f^gamma（gamma 控制年龄分布偏斜），深度仍走上面的公式。**代价与纯噪声完全相同**。

- **4 输出范围**：随机场模型（可作用到无限地图）

  1. **深海盆地不该是纯平滑的**：地球深海有约 100 km 尺度的丘陵，走向平行于洋中脊，幅度约 100-300 m（量级，具体数值请核对原文）。实现：在深海区叠一层**各向异性噪声**，沿脊线方向拉长 4-10 倍，幅度 ±150 m，波长 1-4 个区块。

  4. 该模型天然给出"深海盆地是平的 + 有细纹"，正是双峰直方图右峰保持窄而高的原因（纹理幅度远小于峰间距）。

- **4 输出范围**：统计与判据，无地图生成
- **5 实时性**：不适用。搬入等级【只借思想】
- **6 双峰高程**：有（hypsometry 的经典参考）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：有大陆边缘（陆架坡折作为大陆边界）
- **8 内海与孤岛**：**这是最接近"内海与孤岛"问题的一条**——它讨论的正是"如何划一条线把某块陆壳算作一个大陆"，也就是"连通性判据"。

- **10 对本项目的可借鉴点**：

### A12. Wyatt (1986)：后三叠纪大陆 hypsometry 与海平面

- **1 名称 + 链接**：B. W. Wyatt (in A. Hallam ed.), *Post-Triassic continental hypsometry and sea level*, Journal of the Geological Society 143 (1986) 907 — https://doi.org/10.1144/gsjgs.143.6.0907
- **2 一句话原理**：用显生宙的大陆高程分布变化解释海平面长期波动，即"海平面变化 = 大陆高程分布变化 + 洋盆体积变化"。
- **3 类别**：实测统计 + 解析解释 / 历史地质学
- **4 输出范围**：时间序列（海平面 vs 时代），无地图
- **5 实时性**：不适用。搬入等级【只借思想】
- **6 双峰高程**：有（大陆 hypsometry 的形状与海平面的关系）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：有大陆架淹没/出露的讨论（陆架是海平面切在 hypsometry 曲线上的直接后果）
- **8 内海与孤岛**：涉及"大陆被浅海淹没形成陆表海（epicontinental sea）"，是"内海"的地质对应物。
- **9 语言/依赖/许可证/star**：论文（JGS）
- **10 对本项目的可借鉴点**：
  1. **关键洞见：陆架的宽度是海平面在双峰曲线上切点位置的函数**。当海平面靠近大陆台地峰时，会切出极宽的浅海（陆表海）——这正是"内海"的成因。
  2. **反过来说：要避免内海，就别让海平面切在大陆台地峰的缓慢上升段上**，而要让大陆度场在台地附近有一个**陡峭的"边缘"**（即大陆台地以较窄的过渡带结束）。这给了一条可实现的规则：
     - 大陆度场 c(x,z) 的直方图应有一个明显的"平台 + 陡壁"，而不是高斯。
     - 实现：c = smoothstep(sigmoid 型) 作用于低频噪声，使 c 的分布在两端堆积（这正是"双峰"在控制场上的体现）。
  3. 与 A2 的"调海平面而不是调阈值"配合：海平面固定在台地峰的**下方一点**，就能得到"窄陆架 + 无内海"。
  4. 若将来做"冰期/间冰期"，可把海平面整体平移，届时内海会自动出现——这反而是玩法素材（地球历史上确实如此）。

### A14. Balmino et al. (2012)：超高阶地形/重力球谐谱（地球地形的功率谱）

- **2 一句话原理**：把地球地形与重力场展开到超高阶球谐（度数千级），给出各阶（即各空间尺度）的能量分布，从而量化地球地形的**功率谱**（"Kaula 律"的经验版本）。
- **3 类别**：实测数据处理 / 谱分析
- **4 输出范围**：全球球谐系数（有限模型）
- **5 实时性**：不适用（离线拟合）。搬入等级【离线标定后搬】（产物是 1-2 个谱斜率指数）
- **6 双峰高程**：无（谱分析不管直方图形状）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无（但各尺度能量分布会把洋中脊尺度、海山尺度体现为谱上的鼓包）
- **8 内海与孤岛**：不涉及
- **9 语言/依赖/许可证/star**：论文（Journal of Geodesy）；球谐系数产品通常可申请获取。
- **10 对本项目的可借鉴点**：
  1. **给"噪声该用多少 octave、每 octave 多少振幅"提供经验依据**：地球地形功率谱近似幂律 S(k) ~ k^-beta，beta 随频段不同（大约 2-3，具体以原文谱图为准）。fBm 的功率谱对应 S(k) ~ k^-(2H+2)，因此粗略对应 **H ~ 0.0-0.5**。
  2. **与第 3 条结论（H ~ 0.6-0.8 才能得到 D ~ 1.2-1.4）冲突吗？** 不冲突，但必须**分区处理**：海岸线维数由**海岸线所在尺度段的 H** 决定；小尺度粗糙度由高频 octave 的振幅决定。推荐做法：
     - 低频（大陆尺度，>500 km）：H_low ~ 0.7（保证海岸线 D ~ 1.3）
     - 高频（<10 km，纹理）：用更小 H 或额外的高频层，只要振幅足够小，就不会显著改变海岸线的分形维数
  3. **验证方法（可写成离线测试）**：对自己生成的高程场做 2D FFT 径向平均，画 log-log 谱，看斜率是否落在 2-3；再对海陆二值图做盒计数法测 D。**这两项应作为回归测试固化下来**。
  4. 不必真的用球谐函数实现（球谐在无限平面上不适用）；只借"谱斜率"这一个标量。

### A15. Klinkenberg & Goodchild (1992)：地形分形维数的"方法依赖性"

- **1 名称 + 链接**：B. Klinkenberg & M. F. Goodchild, *The fractal properties of topography: A comparison of methods*, Earth Surface Processes and Landforms 17 (1992) 217-234 — https://doi.org/10.1002/esp.3290170303
- **2 一句话原理**：用 7 种方法测 55 个 DEM 的分形维数，发现**自相似模型对部分地貌拟合很好、对部分地貌拟合不佳**，且不同方法给出的维数系统性不同（dividers 法一致偏低）。
- **3 类别**：实测方法学 / 地貌计量学
- **4 输出范围**：维数测量值表，无地图生成
- **5 实时性**：不适用（离线验证用）。搬入等级【只借思想】（但它是我们 D 指标的**测量规范**）
- **6 双峰高程**：无
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无（按地貌省分组测量）
- **8 内海与孤岛**：无
- **9 语言/依赖/许可证/star**：论文（ESPL）
- **10 对本项目的可借鉴点（非常重要，直接决定验收方式）**：
  1. **D 不是唯一值，取决于测量方法**。所以项目指标"D ~ 1.2-1.4"必须**绑定一种测量方法**，否则无法验收。建议锁定：**在海陆二值图上用盒计数法（box counting），盒子边长取 16 m -> 16 km 的对数等分**（正好对齐块大小）。
  2. **必须在同一尺度区间内比较**。文献表明维数随尺度区间变化。项目应固定：尺度从"1 个区块（16 m）"到"整个大陆宽度（数千 km）"取 5-8 个倍频程。
  3. **对"分段/多标度"地形，单一 D 会失真**：该文明确指出自相似模型只是近似。→ 我们不必强求单一 D；可分别报告"D(小尺度)"与"D(大尺度)"，只要主尺度段落在 1.2-1.4 即可。
  4. **测量代码可以直接写在 Java 测试里**：块级世界天然是栅格，盒计数法实现 30 行。建议作为 CI 回归测试（每次改噪声参数都跑）。
  5. 该文的"方法敏感性"也是**给用户/评审的解释武器**：如果有人说"D 不对"，先问用什么方法、什么尺度段测的。

### A16. Dietler & Zhang (1992)：瑞士景观的分形维数

- **1 名称 + 链接**：G. Dietler & Y.-C. Zhang, *Fractal aspects of the Swiss landscape*, Physica A 191 (1992) 213-219 — https://doi.org/10.1016/0378-4371(92)90530-4
- **2 一句话原理**：对瑞士地形图上的**等高线**做分形分析，测量等高线维数并检验自仿射标度关系。
- **3 类别**：实测分形分析 / 地貌学
- **4 输出范围**：维数测量值，无地图生成
- **5 实时性**：不适用。搬入等级【只借思想】
- **6 双峰高程**：无（山地单峰地貌）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无
- **8 内海与孤岛**：无
- **9 语言/依赖/许可证/star**：论文（Physica A）
- **10 对本项目的可借鉴点**：
  1. **"等高线维数"是比"海岸线维数"更好的验收指标**，因为海岸线只有一条（海平面），而等高线有一族。项目可以用**多个高程阈值**（如 -200 m、0 m、+200 m、+1000 m）各测一次 D，检查是否稳定在 1.2-1.4。这能查出"只有海平面附近做得对、其他地方是糊的"这类问题。
  2. **等高线的分形维数与地形面的 Hurst 指数关系为 D = 2 - H**（自仿射面等值线维数的标准结果）。这条关系是全篇最可操作的公式之一：**给定目标 D 直接反解 H**。想要 D = 1.2 -> H = 0.8；D = 1.3 -> H = 0.7；D = 1.4 -> H = 0.6。
  3. **注意该关系假设统计自仿射**。Klinkenberg & Goodchild（A15）提醒该假设只是近似，所以实测 D 与 2-H 会有 0.05-0.1 的偏差，标定时以实测为准。
  4. 实现上：Perlin/simplex 多倍频叠加 + 振幅按 2^(-H*n)（或 persistence = 2^-H）衰减，就是离散 fBm。**H 是唯一需要调的参数**，且它是纯常量，运行时零成本。

### A17. Mandelbrot (1967)：海岸线分形维数的原始文献

- **1 名称 + 链接**：B. B. Mandelbrot, *How Long Is the Coast of Britain? Statistical Self-Similarity and Fractional Dimension*, Science 156 (1967) 636-638 — https://doi.org/10.1126/science.156.3775.636
- **2 一句话原理**：海岸线长度依赖测量尺度（海岸线悖论），因为海岸线是统计自相似的、具有非整数维数；论文给出英国西海岸 D 约 1.25 的著名估计。
- **3 类别**：理论奠基 / 实测
- **4 输出范围**：维数，无地图
- **5 实时性**：不适用。搬入等级【只借思想】
- **6 双峰高程**：无
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无
- **8 内海与孤岛**：无
- **9 语言/依赖/许可证/star**：论文（Science，付费；广为转载）
- **10 对本项目的可借鉴点**：
  1. **D ~ 1.25 这个经典值就在项目目标区间 [1.2, 1.4] 内**，说明项目的海岸线指标是"真实地球级"的，不是拍脑袋。可作为设计文档的引用依据。
  2. **海岸线长度是尺度的函数**：L(e) ~ e^(1-D)。用 D = 1.3 计算，块级 16 m 与"卫星视角 1 km"下测得的海岸线长度会差约 3 倍。→ **本项目不需要"真实长度"，但需要长度随尺度正确变化**；这正好由 H 自动保证。

  4. 若使用直方图变换（A1/A2），必须保证变换是**单调**的，否则会改变等值线的拓扑与维数。

- **10 对本项目的可借鉴点**：

  2. **实用做法：固定海平面，忽略体积反馈**。文献的价值是告诉我们忽略它会造成多大偏差（数百米量级，陆地占比可漂移几个百分点）。
  3. 若将来要做"海平面随洋中脊密度变化"的动态效果，这条给了线性化的量级（数百米 / 洋盆体积百分变化）。

### A23. Zheng & Wang (2023)：全球海沟深度的主控因素

- **1 名称 + 链接**：Zheng, Wang et al., *Primary controlling factors of global ocean trench depth and its linkage with subduction zone kinematics*, Geomorphology (2023) 108812 — https://doi.org/10.1016/j.geomorph.2023.108812
- **2 一句话原理**：统计全球海沟深度，并回归分析其与俯冲板片年龄、汇聚速率、沉积物厚度等运动学参数的关系，找出主控因素。
- **3 类别**：实测统计 + 回归
- **4 输出范围**：全球海沟点/段数据表
- **5 实时性**：不适用。搬入等级【离线标定后搬】（产物是"海沟深度范围 + 与板片年龄的近似关系"）
- **6 双峰高程**：无（海沟是双峰之外的极端负异常）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：**有海沟**（本篇最直接）
- **8 内海与孤岛**：涉及弧后盆地（可作"内海"的成因案例）
- **9 语言/依赖/许可证/star**：论文（Geomorphology）
- **10 对本项目的可借鉴点**：
  1. **海沟深度不是自由美术参数**：地球海沟深度集中在约 -6 到 -10 km（请以原文统计为准），且越老的板片越深。→ 可写 trenchDepth = f(板片年龄)，板片年龄复用 A8 的洋壳年龄场。
  2. **海沟宽度约 50-100 km、相对周围洋底深 2-4 km**，这种"窄而深"的形态必须显式建模，否则会变成一大片低洼。
  3. **弧后盆地是"内海"的合法成因**：若未来想要少量内海，这是最像地球的生成机制（岛弧在外、弧后盆地在内）。
  4. 本项目"内海 = 0"可理解为"俯冲带配置不允许形成弧后盆地"，即所有海沟都位于大陆外缘而非大洋内部。

### A24. Stern (2002)：俯冲带综述（岛弧 / 海沟 / 弧后盆地的完整框架）

- **1 名称 + 链接**：R. J. Stern, *Subduction Zones*, Reviews of Geophysics 40 (2002) 1012 — https://doi.org/10.1029/2001RG000108
- **2 一句话原理**：系统总结俯冲带的结构与产物：海沟、增生楔、岛弧/陆弧、弧后盆地、弧前盆地，以及它们的空间尺度、地形特征与形成条件。
- **3 类别**：综述 / 构造地质学
- **4 输出范围**：概念框架 + 尺度表，无地图生成
- **5 实时性**：不适用。搬入等级【只借思想】+【离线标定后搬】（尺度表可直接当参数）
- **6 双峰高程**：无（但解释了极端正/负地形异常的成因）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：**有岛弧、海沟、弧后盆地**（本条是"岛弧"要素最权威的单一来源）
- **8 内海与孤岛**：有——弧后盆地 = 内海的成因
- **9 语言/依赖/许可证/star**：综述论文（Reviews of Geophysics）
- **10 对本项目的可借鉴点**：
  1. **岛弧的空间尺度**：弧到海沟距离约 100-300 km，弧宽约 50-200 km，弧后盆地宽约 200-500 km（请核对原文数值）。这是"岛弧要素"在世界尺度上的尺寸，也决定 Z 轴周期 20,000,000 内能排下多少个。
  2. **岛弧的平面形态是"弧形"**，通常向大洋凸出。→ 用一段圆弧或有理贝塞尔曲线定义弧脊线，再用"离脊线的距离"生成地形（解析曲线时 O(1)）。
  3. **岛弧 = 一串小岛还是连续山脉？** 地球两者都有（日本是连续弧，阿留申是岛链）。用户要求"无散落小岛"，所以**应生成连续弧（陆弧/连续岛弧）**，这在地球上同样常见（日本、安第斯）。
  4. **岛弧与大陆的关系**：弧可增生到大陆边缘（安第斯型）或独立于大洋中（马里亚纳型）。要满足"陆地互相连通"，就选**安第斯型**：岛弧是大陆边缘的一部分，不会被判为孤岛。
  5. **与 A13 配合**：海沟（负）-> 弧前（浅）-> 岛弧（正）-> 弧后（负或陆），这条断面线可用一维分段函数实现，代价可忽略。

### A25. Dahlen (1990)：临界楔体理论（造山带 / 增生楔的形状与坡度）

- **1 名称 + 链接**：F. A. Dahlen, *Critical taper model of fold-and-thrust belts and accretionary wedges*, Annual Review of Earth and Planetary Sciences 18 (1990) 55-99 — https://doi.org/10.1146/annurev.ea.18.050190.000415 （原始文献：Davis, Suppe & Dahlen, JGR 88 (1983) 1153 — https://doi.org/10.1029/JB088iB02p01153 ）
- **2 一句话原理**：造山带与增生楔会自我调整到"临界楔体"形状：地表坡度 alpha 与底部滑脱坡度 beta 满足由岩石强度与孔隙流体压力决定的临界关系；太陡就崩塌、太缓就继续增厚。
- **3 类别**：解析力学 / 构造地质学
- **4 输出范围**：一维剖面几何关系，可作用到无限地图
- **5 实时性**：闭式关系。搬入等级【离线标定后搬】（得到 1-2 个坡度常数）
- **6 双峰高程**：无（管的是双峰之上的"额外"地形）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：**有岛弧/造山带与增生楔**（海沟内侧的楔体就是 A24 里的弧前区）
- **8 内海与孤岛**：无
- **9 语言/依赖/许可证/star**：综述论文（Annual Reviews）
- **10 对本项目的可借鉴点**：
  1. **山脉坡度有物理上限**：临界楔体地表坡度通常在 2-8 度之间（干燥岩石摩擦、高孔隙压时更缓）。→ 山脉**平均坡度**应落在这个区间，超出就"不像地球"。
  2. **山脉高度上限 = 平均坡度 x 山脉半宽**。例：宽 500 km 的山脉带、坡度 4 度 -> 峰高约 17 km（显然超过地球实际，说明真实山脉受侵蚀限制）。→ 实践上应再加**侵蚀剥蚀上限**（由河流下切模型限制），或简单地把山脉峰值钳制在 +4~+6 km。
  3. **剖面形状**：临界楔体是**上凸的三角形剖面**（靠近海沟处坡度渐增），不是对称高斯。→ 用 h(t) = H * t^0.7 之类的幂函数（t 为从楔体前缘起的归一化距离）比高斯更像地球。
  4. **碰撞造山 vs 增生楔用两种剖面**：碰撞造山（A21 的连接带）更陡更对称；增生楔（俯冲带）是不对称三角形。两种山脉用两种剖面，世界会更丰富。

### B1. PlaSim / Planet Simulator（Fraedrich et al. 2005）+ Green planet & Desert world

- **1 名称 + 链接**：
  - K. Fraedrich, H. Jansen, E. Kirk, U. Luksch, F. Lunkeit, *The Planet Simulator: Towards a user friendly model*, Meteorologische Zeitschrift 14 (2005) 299-304 — https://doi.org/10.1127/0941-2948/2005/0043
  - 同刊续篇：*The Planet Simulator: Green planet and desert world*, Meteorologische Zeitschrift 14 (2005) 305-314 — https://doi.org/10.1127/0941-2948/2005/0044
- **2 一句话原理**：中等复杂度的全球大气环流模型（谱动力核心 + 简化物理），可把下垫面设成任意组合（全海洋 / 全陆地 / 混合），用极低算力跑出全球气候态。
- **3 类别**：中等复杂度 GCM（EMIC / 简化 GCM）
- **4 输出范围**：全球有限网格（T21-T42 谱截断，约 5-10 度），**有限地图**，但**输入可以是任意程序化下垫面**
- **5 实时性**：**不能运行时求值**（跑一次数分钟到数小时）。搬入等级【离线标定后搬】——用它测出"给定陆地占比/布局 -> 气候态"的响应，然后**拟合一个 2-3 参数的近似公式**在运行时用
- **6 双峰高程**：无（PlaSim 有地形输入，但本身不生成地形；默认下垫面无起伏）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无（地形是输入）
- **8 内海与孤岛**：无（但可以输入任意海陆分布，因此**可以拿它做"内海个数 -> 气候"的对照实验**，这是我们唯一能直接做这个实验的工具）
- **9 语言/依赖/许可证/star**：Fortran；PlaSim 长期以源码分发（早年版权受限，ExoPlaSim 分支为 GPL-2.0）；star 数见 B2
- **10 对本项目的可借鉴点（可写代码）**：
  1. **"Green planet vs Desert world" 就是 aquaplanet / land planet 的原始实验**，直接对应本项目"陆地占比可标定"这个指标。→ 离线跑 3 个点（陆地 20% / 30% / 40%），记录全球平均温度与温度带位置，用来标定"陆地占比 -> 气候"的经验曲线。
  2. **PlaSim 的输入是一张下垫面图（陆地/海洋 + 粗糙度 + 反照率 + 地形高度）**。所以本项目的生成器输出**可以无缝喂给 PlaSim 做验证**：把我们的 (x,z) 世界按纬度重采样成 5 度格点，跑 PlaSim，看气候是否像地球。这是**可执行的验证闭环**，非常值得做。
  3. **不需要把 PlaSim 搬进 Java**：只要用它做一次离线实验，得到"我们的世界 -> 气候态"的对照，然后把结论固化成规则（例如"陆地占比 29% 时，纬度 30 度附近应出现副热带高压干旱带"）。
  4. **提醒**：PlaSim 的纬向平均气候对陆地布局不敏感、但对**海陆经向分布**敏感——这正是我们 Z 轴是纬度、X 轴是"经度"的世界的核心问题（见 B12）。

### B2. ExoPlaSim（Paradise, Macdonald, Menou, Lee, Dressing 2022）：给类地行星用的 PlaSim 扩展

- **1 名称 + 链接**：A. Paradise, E. Macdonald, K. Menou, C. Lee, F. Dressing, *ExoPlaSim: Extending the Planet Simulator for exoplanets*, MNRAS 511 (2022) 3272 — https://doi.org/10.1093/mnras/stac172 ｜免费预印本 https://arxiv.org/abs/2107.07685 ｜代码 https://github.com/alphaparrot/ExoPlaSim （Python 前端 + Fortran 内核；GPL-2.0；约 121 star，2026-09 查询）
- **2 一句话原理**：把 PlaSim 改造成能跑任意恒星光谱、任意自转轴/自转速率、任意大气成分的行星，并加上冰川与碳循环演化，用于研究类地行星的气候与宜居性。
- **3 类别**：简化 GCM + 行星气候演化框架
- **4 输出范围**：全球有限网格（可设任意分辨率档位），**有限地图**
- **5 实时性**：不可运行时求值（分钟-小时级）。搬入等级【离线标定后搬】
- **6 双峰高程**：无（地形是输入边界条件）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无
- **8 内海与孤岛**：可输入任意海陆掩膜，因此**可以做"内海个数/大陆块数 -> 气候"的对照实验**
- **9 语言/依赖/许可证/star**：Python + Fortran；GPL-2.0；约 121 star；依赖 netCDF、编译器工具链
- **10 对本项目的可借鉴点**：
  1. **最简单的可执行验证路径**：本项目生成的世界 -> 重采样成 ExoPlaSim 的下垫面（陆地/海洋掩膜 + 可选地形高度）-> 跑出温度/降水 -> 与地球气候态对比。**这是"我们的世界像不像地球"最硬的验证方式**，且 Python 接口比 PlaSim 原版友好得多。
  2. **Python 接口意味着可以自动化**：写一个脚本，对 N 个种子各跑一次，统计"温度带数量、沙漠面积、极地冰盖范围"，作为世界质量评分。
  3. **它显式建模冰川与碳循环**：若本项目将来要做"气候随时间演化"，ExoPlaSim 的冰川模块提供了现成的物理参数化，可离线拟合。
  4. **注意它的定位是"宜居性研究"，不是地貌研究**：它不会告诉你大陆架多宽，只会告诉你气候如何。**B 节的全部文献都只解决"气候"，地貌仍要靠 A 节。**

### B3. ROCKE-3D（Way et al. 2017）：NASA GISS 的岩石行星 GCM

- **2 一句话原理**：把 NASA GISS ModelE 地球 GCM 改造成可模拟任意 rocky planet（不同大小、自转、大气、海陆分布、海洋深度）的三维气候模型。
- **3 类别**：全复杂度 GCM（比 PlaSim 重得多）
- **4 输出范围**：全球有限网格（约 2-4 度），有限地图
- **5 实时性**：极重（需 HPC，天级）。搬入等级【只借思想】（对本项目而言太重，只能引用其结论）

- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无（但**支持设定海洋深度与海洋热输运**，这一点比 PlaSim 更接近真实）

- **9 语言/依赖/许可证/star**：Fortran + MPI，NASA 开源（GitHub 上有 nasa 组织下的镜像，本次未能确认唯一官方仓库地址，**故不给不确定的仓库链接**；论文与作者机构页面为准）
- **10 对本项目的可借鉴点**：

  3. **对本项目最实际的用途是"引用权威"**：当需要论证"单块大陆 + 29% 陆地占比是合理的地球式构型"时，引 ROCKE-3D / PlaSim 的系列实验即可。
  4. 不建议把任何全复杂度 GCM 搬进 Java。

### B4. CLIMBER-2 与 CLIMBER-X：中等复杂度地球系统模型（EMIC）

  4. 实际用法：把本项目生成的大陆轮廓**手动转成 CLIMBER 的 10 度掩膜**（几百个格点，可手写），跑一次得到气候态，作为世界设计的气候基准。

### C1. Geodynamic World Builder（Fraters & Thieulot 2019）—— 任务点名的 WorldBuilder

- **1 名称 + 链接**：M. Fraters, C. Thieulot, W. van den Berg, A. P. van den Berg, *The Geodynamic World Builder: a solution for complex initial conditions in numerical modeling*, Solid Earth 10 (2019) 1785-1807 — https://doi.org/10.5194/se-10-1785-2019 ｜代码 https://github.com/GeodynamicWorldBuilder/WorldBuilder （C++，LGPL-2.1，约 41 star，2026-09 查询；已被 ASPECT 等数值模拟软件采用）
- **2 一句话原理**：用 JSON 描述"几何要素"（大陆、洋壳、海沟、地幔柱、断层等），由程序在任意查询点 (x,y,z) 上**O(1) 求值**出该点的材质/温度等属性，用于给地幔对流等数值模型提供复杂初始条件。
- **3 类别**：几何建模框架 / 地球动力学数值模拟基础设施
- **4 输出范围**：**无限程序化（任意坐标插值求值）**——它本身不生成地图，而是在查询点上求值，这一点与我们的架构完全一致
- **5 实时性**：**运行时 O(1) 求值**（对每个 feature 求距离并混合；feature 数少时是常量时间）。搬入等级【直接搬】（**架构级借鉴，最高优先级之一**）
- **6 双峰高程**：无（它输出的是"材质/密度/温度"，不是高程；但双峰所需的"陆壳/洋壳二分"正是它的原生能力）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：有——支持**大陆、洋壳、海沟、洋中脊、地幔柱**等要素，且每个要素可用多边形/曲线 + 距离衰减描述
- **8 内海与孤岛**：不处理（无拓扑分析）
- **9 语言/依赖/许可证/star**：C++；LGPL-2.1；约 41 star；依赖 JSON 解析（自带）
- **10 对本项目的可借鉴点（**架构照抄级**）**：
  1. **"要素 + 距离衰减 + 混合"的求值模型**就是本项目最该采用的架构：把世界定义成若干**要素（feature）**——大陆核、造山带、洋中脊、海沟、岛弧——每个要素有几何（点/线段/多边形/曲线）与影响半径，查询时对每个要素算"有符号距离 -> 权重"，再按权重混合出"大陆度 c(x,z)"。
  2. **O(1) 的来源**：要素数固定为常数（例如 5-20 个），每个要素的距离计算是解析的（点到线段距离、点到曲线的近似距离）。**总代价 = 常数 x 少量算术**，完全满足"接近纯噪声"的性能要求。若要素随 X 无限重复，就用"X 取模到有限窗口"的技巧（但会破坏非周期性，见第 5 条）。
  3. **JSON 驱动 = 可热重载**：把世界的"大陆布局"写在 JSON 里，改布局不需要重新编译 Java。**强烈建议照抄这个设计**（不过最终要烘成常量的话，可以在构建期把 JSON 转成 Java 常量数组）。
  4. **它证明了这套架构在科学界的可接受性**：地球动力学界用它构造复杂初始条件，说明"几何要素 + 距离衰减"足以表达大陆、洋壳、海沟等真实构造——**我们不是在用游戏技术糊弄科学**。
  5. **对本项目最关键的限制**：WorldBuilder 的要素是**有限个**、放在**球面**上；本项目要 X 无限非周期，所以必须另加一层"低频噪声驱动的要素参数调制"（例如：把要素的半径、位置偏移、强度用 1D 噪声沿 X 调制），才能在保持 O(1) 的同时获得无限不重复。
  6. **可借的具体几何算法**：点到线段/点到折线的最近距离、多边形内外判定（射线法）、按距离的 smoothstep 混合权重。这三样在 Java 里各 20-40 行，可直接手写。

### C2. Cortial, Peytavie, Galin et al. (2019)：Procedural Tectonic Planets

- **1 名称 + 链接**：Y. Cortial, A. Peytavie, E. Galin et al., *Procedural Tectonic Planets*, Computer Graphics Forum 38 (2019) — https://doi.org/10.1111/cgf.13614

- **6 双峰高程**：**有**——按板块类型分别给出大陆地台与洋盆两个基准高度，是"双峰"的显式实现
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：**有海沟、洋中脊、造山带**（这是本篇的核心贡献），岛弧视边界类型而定
- **8 内海与孤岛**：不处理（无拓扑保证）
- **9 语言/依赖/许可证/star**：论文（CGF 付费）；无公开代码（本次未查到，故不给链接）
- **10 对本项目的可借鉴点**：
  1. **"板块边界类型决定地形贡献"是最高层的设计模式**：不必模拟板块运动，只需给每条边界标一个类型，然后用查表的方式给高程贡献：
     - 离散边界（拉张）-> 洋中脊隆起（+2~3 km 相对深海）
     - 汇聚边界（俯冲）-> 海沟（-2~4 km）+ 内侧岛弧（+2~3 km）

### C3. Derzapf & Ganster (2011)：River Networks for Instant Procedural Planets

- **1 名称 + 链接**：E. Derzapf, B. Ganster et al., *River Networks for Instant Procedural Planets*, Computer Graphics Forum 30 (2011) — https://doi.org/10.1111/j.1467-8659.2011.02052.x

- **3 类别**：学术计算机图形学（实时程序化地形 + 水文）
- **4 输出范围**：整颗行星，程序化生成
- **5 实时性**：**接近实时/即时**。搬入等级【直接搬】（核心思想）/【离线标定后搬】（若要全局一致的河网）
- **6 双峰高程**：无（只管陆地内部的水系）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无
- **8 内海与孤岛**：不处理，但**河网与湖泊的生成会给"内陆水体"提供机制**（这是内海的反面教材：内陆湖不是内海，但视觉上相似，需要区分）
- **9 语言/依赖/许可证/star**：论文（CGF）；无公开代码链接（本次未查到）
- **10 对本项目的可借鉴点**：
  1. **关键思想："河网不是模拟出来的，而是构造出来的"**。→ 本项目若要做河流/湖泊，不应做侵蚀模拟（需要全局迭代），而应**用解析方法构造河网**：给定"山地骨架"（解析曲线），沿最陡下降方向生成确定性路径。

  4. **"instant" 这个词是重点**：该文的目标就是"程序化行星上即时可得的河流"。与本项目的性能目标同源。

### C4. Paris, Galin et al. (2019)：Terrain Amplification with Implicit 3D Features

- **1 名称 + 链接**：A. Paris, E. Galin, E. Guérin et al., *Terrain Amplification with Implicit 3D Features*, ACM Transactions on Graphics 38 (2019) — https://doi.org/10.1145/3342765
- **2 一句话原理**：给定一张**低分辨率**地形（例如 1 km 格网），用隐式三维要素与程序化噪声把它"放大"成任意高分辨率细节，同时**保持原有的大尺度形状**（山脊、河谷位置不变）。
- **3 类别**：学术计算机图形学（地形放大 / 多尺度细节合成）
- **4 输出范围**：任意大范围，**逐点 O(1) 求值**（放大是局部操作）
- **5 实时性**：**运行时 O(1) 求值**。搬入等级【直接搬】——**这是本文件里与"块级 16x16 + O(1)"最契合的一篇**
- **6 双峰高程**：无（它放大已有地形，不管分布形状；但放大前的大尺度形状可以被我们做成双峰）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无（要素类型可自定义，理论上可定义"陆坡要素"）
- **8 内海与孤岛**：不处理（放大不改变拓扑，**这本身是个优点**：海岸线拓扑由低频控制，高频不会凭空造岛）
- **9 语言/依赖/许可证/star**：论文（ACM TOG 付费）；作者团队另有公开代码与演示（本次未逐条核实链接，故不给）
- **10 对本项目的可借鉴点（**架构级，强烈建议精读**）**：
  1. **核心思想：把"低频控制"和"高频细节"解耦**。低频（本项目的双峰 + 大陆度）决定世界的骨架；高频只做**振幅受约束**的细节。→ 这正是"零预计算 + O(1)"能够做到"大陆尺度合理"的关键。
  2. **"放大不改变拓扑"对本项目极其重要**：用户要求"无散落小岛"。如果高频细节的振幅被限制在"不会把海岸线切成新岛"的范围内（振幅 < 局部 |h - seaLevel| 的某个比例），就能从数学上保证不产生新岛。→ **可实现规则：细节层振幅 A(x,z) = k * max(0, |h_low - seaLevel| - margin)**，即离海平面越近，细节越弱（这同时也让海岸线更平滑——但注意别削掉分形维数，见第 4 条）。
  3. **它使用的隐式要素（山脊线、河谷线、悬崖线）** 可以直接搬到本项目：用解析曲线 + 距离场生成山脊/河谷，而不是靠噪声碰运气。**这解决了"噪声出来的山脉不像山脉"的经典问题**。
  4. **警告（与第 3 条结论的冲突）**：如果为了"不产生小岛"而把海岸线附近的细节削平，海岸线的分形维数会下降。→ 折中方案：海岸线的分形维数由**低频场的 H**（H = 0.6-0.8）保证，而不是由高频细节保证。这样削平高频不影响 D。
  5. **建议的实现优先级**：本项目的噪声管线应分成三层——(a) 双峰基线（低频，来自大陆度场）；(b) 地貌要素（山脊/海沟/洋脊，解析曲线距离场）；(c) 细节噪声（振幅受 |h - seaLevel| 调制）。

### C5. Schott, Galin et al. (2024)：Terrain Amplification using Multi-Scale Erosion

- **1 名称 + 链接**：H. Schott, E. Galin et al., *Terrain Amplification using Multi Scale Erosion*, ACM Transactions on Graphics 43 (2024) — https://doi.org/10.1145/3658200
- **2 一句话原理**：用**多尺度侵蚀算子**（把河流下切/坡面扩散在不同尺度上预计算成可复用的算子）来做地形放大，使放大后的细节具有真实的侵蚀地貌特征（河谷、坡面），而不是简单噪声。
- **3 类别**：学术计算机图形学（侵蚀增强的地形放大）
- **4 输出范围**：任意范围，逐点求值（算子可预计算）
- **5 实时性**：求值 O(1) 但需要预计算的算子（多尺度滤波器）。搬入等级【离线标定后搬】（算子要烘成常量系数；若用解析近似则可【直接搬】）
- **6 双峰高程**：无
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无（但侵蚀会自然产生"陆坡-平原"式的坡折）
- **8 内海与孤岛**：不处理
- **9 语言/依赖/许可证/star**：论文（ACM TOG）；作者团队（Galin/Peytavie 组）有大量公开代码与项目页
- **10 对本项目的可借鉴点**：
  1. **"把侵蚀变成可复用的多尺度算子"是解决"侵蚀需要全局迭代"的钥匙**。传统侵蚀模拟必须迭代整个地图（违反零预计算），而多尺度算子可以**离线烘成一组系数**，运行时只做滤波。
  2. **对本项目的具体做法**：离线跑一次 FastScape（C9）或 Landlab（C10）在**一块 256x256 的合成地形**上，得到"侵蚀后的地形"；然后拟合出"侵蚀前后振幅随尺度的衰减曲线"（每条 octave 的增益系数）。运行时把 fBm 的每个 octave 乘以这个增益。**产物是 8-12 个浮点数常量，运行时零成本。**
  3. **这是"把离线模拟的结论搬进 O(1) 管线"的标准范式**：不搬地图，只搬**谱增益**。
  4. **它的多尺度思想也可用于"海底"**：洋中脊附近的丘陵（A9）在不同尺度上的振幅分布，同样可以烘成增益曲线。

### C6. Cordonnier, Braun, Cani, Beneš, Galin et al. (2016)：Large Scale Terrain Generation from Tectonic Uplift and Fluvial Erosion

- **1 名称 + 链接**：G. Cordonnier, J. Braun, M.-P. Cani, B. Beneš, E. Galin, A. Peytavie, É. Guérin, *Large Scale Terrain Generation from Tectonic Uplift and Fluvial Erosion*, Computer Graphics Forum 35 (2016) — https://doi.org/10.1111/cgf.12820
- **2 一句话原理**：用"**构造抬升场（uplift）** + **河流下切（stream power）**"两个物理算子生成大陆尺度地形：抬升场决定山脉位置与高度，河流下切雕刻出河谷、分水岭和坡面，最终得到与真实大陆尺度地形统计相似的结果。

- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：**有山脉、河谷、分水岭**；海沟/洋中脊不在范围内

- **9 语言/依赖/许可证/star**：论文（CGF）；作者团队有公开代码/项目页（本次未逐条核实链接，故不给）
- **10 对本项目的可借鉴点（离线实验的最佳选择）**：
  1. **"抬升场 + 河流下切"是生成"像地球的山脉"的最短路径**。→ 建议做一次离线实验：用 C9 的 FastScape（几十行 Python）在我们设计的大陆度场上跑一次，观察 (a) 山脉是否形成连续山脊而不是噪声包，(b) 海岸线分形维数是多少，(c) 河谷密度。
  2. **可控风险点**：河流下切会把陆地削低、可能切断陆桥导致**内海**。→ 离线实验必须检查"内海个数"，并据此决定"我们的世界到底要不要模拟侵蚀"。
  3. **折中方案**：只在远离海岸线的内陆区域模拟侵蚀效果（用"离海岸距离"调制侵蚀强度）。这仍可 O(1)（用一条离线拟合的"侵蚀强度 vs 离海距离"曲线）。
  4. **抬升场（uplift）这个概念直接可用**：本项目可把"大陆度场"直接当抬升场——大陆度高的地方抬升强。**这样山脉自动长在大陆内部与碰撞带，而不是随机撒在海上**。极其实用且与物理一致。

### C8. Génevaux, Galin et al. (2013)：Terrain generation using procedural models based on hydrology

- **1 名称 + 链接**：J.-D. Génevaux, E. Galin, É. Guérin et al., *Terrain generation using procedural models based on hydrology*, ACM Transactions on Graphics 32 (2013) — https://doi.org/10.1145/2461912.2461996
- **2 一句话原理**：**反过来做**——先程序化定义河网（河流拓扑与位置），再由河网反推地形高度（河流处最低、分水岭处最高），保证地形与水文完全自洽。
- **3 类别**：学术计算机图形学（逆问题式地形生成）
- **4 输出范围**：任意大范围，逐点求值（河网是构造出来的，不需模拟）
- **5 实时性**：**可 O(1) 求值**（河网由解析/程序化曲线定义，高度 = 到最近河道距离的函数 + 分水岭约束）。搬入等级【直接搬】
- **6 双峰高程**：无（针对陆地内部）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：无
- **8 内海与孤岛**：河网是树状的，天然不产生封闭水体（**优点**）
- **9 语言/依赖/许可证/star**：论文（ACM TOG）
- **10 对本项目的可借鉴点（一条极实用的技巧）**：
  1. **"先定河、后定山"可彻底解决"噪声山脉不像山"**。本项目优先级是海岸线与大陆形态，更实用的变体是：**"先定海沟/洋脊/海岸线，后定高程"**。
  2. **可迁移的数学工具**：**到最近曲线的距离场** + **分水岭的中轴变换**。河流沿中轴，分水岭在两河之间。→ 本项目可用同样方法把"海沟线 + 洋脊线"变成高程：h = f(到海沟线的距离) - g(到洋脊线的距离)。
  3. **树状结构保证"无封闭水体"**：河网是树，树的补集是连通的。→ 同理，若"高地骨架"是树状/连通的，海平面以上区域天然连通，**无内海**。这是"内海 = 0"的拓扑级保证，非常值得借鉴。
  4. **警告**：距离场 O(1) 只对**少量曲线**成立。曲线多则需空间索引（引入状态）。→ 控制要素数量在 10-30 条以内。

### C14. GPlates / pyGPlates：板块重建的标准工具链

- **1 名称 + 链接**：GPlates 官网 https://www.gplates.org/ ｜代码 https://github.com/GPlates/gplates （C++/Python，约 152 star，许可证 GitHub 未能自动识别，**使用前请到官网/仓库确认**）。入门文献：Boyden, Müller et al., *Next-generation plate-tectonic reconstructions using GPlates*, in Geoinformatics (2011) — https://doi.org/10.1017/CBO9780511976308.008 ｜GPlates 栅格重建：Cannon, Lau et al., Solid Earth Discussions 6 (2014) 793 — https://doi.org/10.5194/sed-6-793-2014
- **2 一句话原理**：用旋转文件（rotation model）+ 板块多边形，把地球表面任意地质时刻的几何重建出来，并支持栅格（古地形/古水深）在重建中的重采样。
- **3 类别**：科学软件 / 板块重建工具链
- **4 输出范围**：**有限全球地图**（矢量 + 栅格）
- **5 实时性**：离线（秒-分钟）。搬入等级【离线烘焙查表】
- **6 双峰高程**：无（几何重建；高程需另配 paleo-DEM，见 B15）
- **7 大陆架/陆坡/岛弧/海沟/洋中脊**：有（重建出的板块边界、古洋中脊、古俯冲带）
- **8 内海与孤岛**：可识别（重建的多边形直接给出大陆块与海盆，可统计"块数"）
- **9 语言/依赖/许可证/star**：C++/Python（pyGPlates 是 Python 绑定）；约 152 star；许可证需自行确认
- **10 对本项目的可借鉴点**：
  1. **它是"离线统计真实地球"的标准工具**：用 pyGPlates + B15 的 paleo-DEM，可以批量算出**每个地质时代的**"陆地占比、大陆块数、内海个数、海岸线长度"，形成一张"地球合法参数表"。**这是本文件最推荐做的一件离线工作。**
  2. **它不解决我们的问题**：GPlates 的世界是球面、有限、且依赖真实地球演化史。**与"无限 X 轴 + 种子随机"不兼容**。
  3. **pyGPlates 的 API 设计可借鉴**：把"重建"表达为"对 (点, 时刻) 求值"，这本质上也是一种 O(1)-ish 的查询接口（给定旋转文件）。我们的"对 (x,z,seed) 求值"是同一类接口的无限版本。

## D. 综合：把 A/B/C 三节汇成可执行清单

### D1. 推荐的管线架构（分层，逐层 O(1)）

| 层 | 输入 | 输出 | 来源依据 | 代价 |
|---|---|---|---|---|
| L0 大陆度场 | (x,z,seed) 低频 fBm + 5-20 个解析要素（大陆核/碰撞带/俯冲带/洋脊线） | c(x,z) ∈ [0,1]，单峰、连通、无内海 | C1（要素+距离衰减）、A11（用连续场而不是二值图做判据）、A21（碰撞带连通） | 常数次噪声 + 常数次点到线段距离 |
| L1 双峰基线 | c(x,z) | 高程基线：陆地台地约 +0.1~+0.3 km，洋盆约 -4~-5 km | A2（双 delta）、A4、A7 | 一次一维 LUT（A1 的逆 CDF） |
| L2 洋底年龄/洋脊 | 洋脊线距离场 | 洋深 -2.5 -> -4.5 km 的台地 | A8（Parsons-Sclater） | 一次 sqrt/exp |
| L3 大陆边缘三段 | c 或离岸距离 | 陆架（~0.1 度）/ 陆坡（~3-6 度）/ 陆隆（<0.5 度） | A10（Harris 2014） | 一次分段函数 |
| L4 构造要素 | 俯冲带/造山带距离场 | 海沟（-2~-4 km 相对洋底）、岛弧（+2~3 km）、造山带（+3~6 km）、洋中脊（+2.5 km） | C2、A23、A24、A25、A13 | 常数次距离场求值 |
| L5 细节噪声 | 局部 Hurst 指数 H(x,z) | 分形海岸线与地形纹理 | A15/A16/A17（D = 2 - H）、A14（谱斜率）、A9（深海丘陵各向异性） | 2-3 层 fBm，octave 增益为常量 |
| L6 振幅约束 | 到海平面的距离 | 抑制近岸细节，防止凭空造岛 | C4（放大不改变拓扑） | 一次乘法 |
| L7 气候/群系 | 高程 + 纬度 + 离海距离 | 温度/降水/群系 | B1-B13（离线标定出的规则） | 少量三角函数 + LUT |

**关键性能结论**：L0-L7 全部是"常数次算术 + 固定层数噪声"，**总代价与纯 fBm 同量级（约 3-6 倍）**，无状态、无缓存、无全局依赖，满足"接近纯噪声"的目标。

### D3. 建议做的离线实验（按性价比排序）

1. **ETOPO 逆 CDF**（半小时）：下载 ETOPO1 -> 统计高程累积分布 -> 输出 16-32 段分段线性 LUT -> 硬编码进 Java。**产物：一个 float[33]。**
2. **海岸线维数标定**（1 小时）：写一个 fBm 生成器 + 盒计数法，扫 H ∈ [0.4, 1.0]，找出"实测 D = 2 - H 的偏差曲线"。**产物：一张 H -> D 的修正表（或直接确认 D = 2 - H 在目标区间可用）。**
3. **FastScape 侵蚀平衡实验**（半天）：合成一张大陆 -> 跑到平衡 -> 测 D、双峰性、谱斜率。**产物：决定"要不要模拟侵蚀"，以及可选的 octave 增益表（C5 范式）。**
4. **PlaSim / ExoPlaSim 气候实验**（1 天）：把我们生成的世界重采样成 5 度下垫面 -> 跑气候 -> 对比地球。**产物：世界设计的"气候合理性"验证。**
5. **pyGPlates + PaleoDEM 统计**（1 天）：算 5 亿年来各时代的陆地占比/大陆块数/内海个数。**产物：指标的合法性区间。**
6. **WorldEngine 反面对照**（2 小时）：跑它的默认世界，用我们的指标打分。**产物：失败模式清单。**

**以上实验全部是离线的，产物全部是标量/小表/曲线，运行时零成本。** 这正是"零预计算"约束下引入科学文献的正确姿势。
