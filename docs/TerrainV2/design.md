# Talos 地形管线 V2 · 设计文档

> 本文件是 V2 地形重构的唯一设计记录，随讨论/实施实时更新。
> 目标：把海陆分布升级到拟真地球级，整条地形管线成为**单一骨架派生的单向管线**，
> 全程保持极低性能开销（运行期单点采样 ≈ 0 增量）。
>
> 当前分支：ArknightsProject-terrain（地形专用分支）。

## 二b. 世界环面几何（洋流的地基）

**把 X 方向也接成周期** → 世界从"无限平面"变成**双周期环面**：

```

```

- **重要区分**：此周期只作用于 **L0 理论场**（洋流/风/气压的"无大陆理想行星"）；
  大陆 L1 仍然无限延伸、不规则、不随 X 周期。洋流查询 = L0 理论场 + L1 大陆折射修正。
- X 周期选 400k（比 Z 的 200k 大）→ 环流圈舒缓、图案重复感低。

### 环面语义（墙纸平铺，非独立区域）
- 世界 = 一个 400k(X) × 200k(Z) 周期域在无限平面上**无缝平铺**；不存在"区域之间缝合"——
  任何世界坐标先折叠到主域 [0,400k)×[0,200k) 再采样，结果即该点值。
- L0 场函数自带周期性：洋流/风/气压跨边界天然连续（场(x,z)=场(x+400k,z)=场(x,z+200k)）。

### 风场塑造（S2，已按 3 圈环流重写）
按权威机制：太阳辐射不均匀加热 → 赤道-极地温差 → 气压差 → 风，再被科里奥利扭向 → 三圈环流。
- Hadley 圈(信风)：东西向 ← + 15° 斜向朝赤道；带状干湿：赤道低压湿
- Ferrel 圈(西风)：东西向 → + 15° 斜向朝极地；副热带高压干
- Polar 圈(极地东风)：东西向 ← + 15° 斜向朝副极地；副极地低压湿、极地高压干
- 南北镜像由科里奥利；大陆影响（季风/海陆热力）留 S3。

### 洋流生成方式（S6 结构原型已建；大陆折射 S6.1 再做）
1. **风驱纬向基底**：信风带往西、西风带往东（GlobalCirculation.windDir 已提供）；
2. **大陆折射**：大陆生成后，洋流绕大陆 → 形成环流圈 + 东岸暖/西岸冷的边界流（S3 大陆完成后实现）；
3. **旋向**：科里奥利（北顺南逆）；
4. **冷暖随流向**：暖流红箭头/寒流蓝箭头（不用纬度底色）。

### 输出场
bandD / windDirX/Z / gyreWarmth / pressureDry / rainfallBase

- pressureDry **显式输出沙漠带信号**（副热带高压带 → 干燥），供 L1 布点 / L5 群系消费（D19）。

## 十c. 洋流权威依据（决定实现顺序）

依据标准海洋学（WHOI 伍兹霍尔 / National Geographic / LibreTexts 物理海洋学《Surface Gyres》）：

- **表层洋流由风驱动**：信风(低纬)推水向西、西风(中纬)推水向东；
- **环流圈(Gyre) = 风 + 大陆弯曲**：没有大陆，海洋只有均匀纬向流；大陆阻挡才把水挤成闭合环流；
- **科里奥利力决定旋向**：北半环流顺时针、南半逆时针；
- **东西岸冷暖不对称(boundary currents)**：大洋西边界(大陆东岸)窄而强暖流；东边界(大陆西岸)宽而弱寒流。

**结论**：风场是发动机、大陆是模具。洋流必须排在大陆之后。
风场按三圈环流塑造（已实现）：信风/西风/极地东风各带 15° 斜向（朝赤道/朝极地/朝副极地）。
