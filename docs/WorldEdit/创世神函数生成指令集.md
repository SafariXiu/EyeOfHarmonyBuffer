# 创世神（WorldEdit）函数生成结构指令集

> 适用版本：本项目 libs/worldedit-v0.0.7.jar（即 GTNH 官方维护的 worldedit-gtnh fork，
> WE 6.1.x 内核，123Technology 工程用的是同款 v0.0.8）。以下内容全部按这个 jar 反编译实测得出，
> 与网上的新版 WorldEdit 教程有差异，以本文为准。

## 0. 这个魔改版与原版的差异（实测）

- 没有 //set 命令（全 jar 944 个类扫描确认，无 //set、无旧版 //mask 命令）。
  整片填充请用：`//g 方块 1`（恒真表达式）或 //replace / //fill / //faces。
- 命令前缀 // 与 / 都可用（配置 no-double-slash=false）。
- 木斧（id 271）是选择工具：//wand 获取；//sel 切换选区类型。
- 默认不限半径、不限方块数（max-radius=-1，max-changed-blocks=-1），小心大选区卡顿/undo 内存。
- 方块 ID 支持 GTNH 的大 ID（>255 的方块直接生成没问题；已知限制是 schematic 保存大 ID 方块有 bug，见 worldedit-gtnh issue #22）。
- 单机作弊模式（或 OP）直接可用全部命令；权限节点为 worldedit.*。

## 4. 函数生成 //generate（重点）

### 4.1 语法

```
//g <方块> <表达式> [-h] [-r] [-o] [-c]
//generate / //gen 同义
```

表达式对选区内的每一个方块求值：返回值 **> 0 判定为在结构内部** → 放置方块；≤ 0 跳过。
-h：只生成壳（内外边界层）。

### 4.2 坐标变量与模式（重要！）

| 变量 | 含义 |
| --- | --- |
| x y z | 当前方块坐标，**默认归一化到 -1..1**（按选区尺寸缩放） |
| type data | 当前默认方块 ID / 数据值；**可在表达式里赋值**覆盖生成方块 |

坐标模式（flag）：
- **默认（无 flag）**：选区被映射到 -1..1，适合写形状公式（球、环…），不关心绝对尺寸。
- -r：使用**原始世界坐标**（适合地形生成类，如噪声地面、按 y 分层）。
- -o：相对放置点（你站的位置）的坐标。
- -c：相对选区中心的坐标。

### 4.3 操作符

```
+ - * / %           四则与取模
^ **                幂（注意：^ 是乘方，不是异或！）
<< >>               左移/右移
< > <= >= == !=     比较
~=                  近似相等（差 < 0.001）
&& || !             逻辑与/或/非
~                   按位取反（-x-1）
++ --               自增/自减（含 x++ x-- 后缀）
= += -= *= /= %= ^= 赋值
? :                 三目运算符，如 a>b ? 1 : 0
;                   语句分隔
```

### 4.4 函数表（实测签名）

**数学**：sin cos tan asin acos atan atan2 sinh cosh tanh sqrt cbrt abs min max ceil floor rint round exp ln log log10
（min/max 支持 2 或 3 个参数）

**噪声（生成地形神器）**：
```
perlin(种子, x, y, z, 频率, 八度, 持续度)     // 值域约 [-1,1]
voronoi(种子, x, y, z, 频率)                  // 细胞状噪声
ridgedmulti(种子, x, y, z, 频率, 八度)         // 山脊状噪声
```

**读写/状态**：
```
query(x, y, z, type, data)      // 读取该点方块；type/data 传 -1 表示通配；
                                // 若传变量则把该点真实方块 ID/数据写回变量；返回 1=匹配 0=不匹配
queryAbs(x, y, z, type, data)   // 同上，但用绝对世界坐标
random()                        // [0,1) 随机数
randint(n)                      // [0,n) 随机整数
megabuf(i) / megabuf(i, 值)      // 跨方块持久缓存（索引 i），第二个参数为写入
gmegabuf(i) / gmegabuf(i, 值)    // 全局持久缓存
closest(x,y,z,type,data)        // 在 megabuf 中找最近的匹配点（返回距离平方）
gclosest(...)                   // 在 gmegabuf 中找
rotate(a, b, 角度)               // 把两个变量绕原点旋转（配合 deform 用）
swap(a, b)                      // 交换两个变量的值
```

**语句**：支持 if else while do for break continue return switch case default，分号结尾。
常量：pi true false。**注意：普通变量每次求值都会重置，跨方块记住状态请用 megabuf/gmegabuf。**

## 5. 结构生成示例库（可直接复制）

> 用法：先 //pos1 //pos2 框出范围，再执行。示例里方块可换成任何 GTNH 方块。

### 5.1 基础几何

```
//g 155:0 x^2+y^2+z^2<1                                 石英球
//g 155:0 x^2+y^2+z^2<1 && x^2+y^2+z^2>0.75             石英球壳（厚壳）
//g -h 155:0 x^2+y^2+z^2<1                              石英球壳（薄壳，同效果）
//g 155:0 (x/0.8)^2+(y/0.6)^2+(z/0.8)^2<1               椭球（压扁的球）
//g 155:0 x^2+y^2+z^2<1 && y>0                           穹顶（下半球）
//g 89:0 x^2+y^2+z^2<1 && y>0                            萤石穹顶（发光！）
//g 133:0 (sqrt(x^2+z^2)-0.45)^2+y^2<0.18^2              甜甜圈圆环
//g 133:0 (sqrt(x^2+y^2)-0.45)^2+z^2<0.15^2              竖立圆环（传送门造型）
//g 24:0 max(abs(x),abs(z))<1-y && y>=0                  砂岩金字塔
//g 1:0 x^2+z^2<(1-y)^2 && y>=0 && y<=1                  正圆锥（塔尖）
//g 49:0 max(abs(x),abs(z))<0.25*(1-y)+0.05 && y>=0 && y<=1   黑曜石方尖碑
//g 89:0 y>x^2+z^2 && y<1                                抛物面碗（聚集点光源）
//g 42:0 max(abs(x),abs(z))<0.5 && y<1                   实心方柱
//g 42:0 max(abs(x),abs(z))<0.5 && y<1 && (abs(x)>0.45 || abs(z)>0.45)   空心方柱（围墙）
```

### 5.2 拱门 / 柱廊（源石祭坛风）

```
//g 155:0 y<sqrt(0.25^2-x^2)+0.25 && abs(x)<0.25 && abs(z)<0.15   半圆拱
//g 155:0 x^2+(y-0.5)^2<0.25^2 && abs(z)<0.15                     圆拱环
//g 155:0 y<0.5-abs(x)*0.5 && abs(x)<1 && abs(z)<0.15              尖拱（哥特式）
```

### 5.3 波浪与噪声地形（塔罗斯2 风味）

```
//g 3:0 y<0.25*sin(4*x)*cos(4*z)                            棋盘波浪地面
//g 2:0 y<0.3*sin(x*6)*sin(z*6)                              草地起伏
//g 1:0 y<0.2*(sin(3*x)+sin(3*z))                            双频起伏
//g -r 1:0 y<62+6*perlin(123,x,0,z,0.008,3,0.5) && y>56      -r 世界坐标噪声地形（丘陵）
//g -r 1:0 y<60+8*ridgedmulti(7,x,0,z,0.006,4) && y>55       -r 山脊地形（山脉）
//g -r 3:0 y<58+5*voronoi(9,x,0,z,0.01) && y>53              -r 细胞状地形（台地）
//g 1:0 x^2+z^2<1 && y<0.15*cos(4*pi*sqrt(x^2+z^2))+0.1 && y>0   环形山（边缘隆起）
```

> 噪声地形强烈建议配合 -r 模式 + 世界坐标写，这样频率参数才是真实每格波长。

### 5.4 分层 / 换色（type、data 变量）

```
//g 35:0 if(x^2+y^2+z^2<1 && y>0){ data=floor(y*8); return 1; } 0
   彩虹分层穹顶（羊毛 0~7 层）
//g 42:0 if(abs(x)<0.3 && abs(z)<0.3 && y<1){ type=floor(y*10)%2==0 ? 41 : 42; return 1; } 0
   金/铁条纹塔（三目运算符）
//g 1:0 if(x^2+y^2+z^2<1){ data=y>0?1:0; return 1; } 0
   上下分层（石/圆石）
```

### 5.5 读取地形贴合生成（query 函数）

```
//g -r 42:0 y==64 && query(x,y-1,z,type,data)==1 && type==1
   在世界 y=64 高度、且下方是石头的位置铺铁块
//g -r 78:0 query(x,y-1,z,type,data)==1 && type==2 && y>60 && y<80
   在草地上方铺一层雪（雪山线）
```

> 技巧：query(x,y-1,z,type,data) 会把 type/data 覆盖为下方方块的真实值，再判断 type==1 即下方是石头。

### 5.7 圆环 + 开窗（内直径 11 格，X 轴 0°/180° 玻璃窗）

```
//pos1                      // 站在环心（或对准环心打点）
//outset 8                  // 六面外扩 8 格，选区中心 = 环心
//g -c 20:0  (sqrt(x^2+z^2)-6.5)^2+y^2<1 && abs(z)<1.5      // 先放 X 轴两侧玻璃窗
//g -c 155:0 (sqrt(x^2+z^2)-6.5)^2+y^2<1 && abs(z)>1.5      // 再放石英环身
```

- 环面公式：`(sqrt(x^2+z^2)-R)^2+y^2<r^2`，R = 环心半径，r = 管截面半径。
- 内径 11 → 洞半径 5.5；2 格粗环（r=1）→ R = 6.5。N 格粗：R = 5.5+N/2，r = N/2。
- 窗：`abs(z)<1.5`（z∈{-1,0,1}）正好落在 +X/-X 两侧；两条指令的 z 区间互补不重叠。
- 只开窗洞（管保持实心）：把窗的条件加 `&& abs(y)<0.8` 限制高度，环身条件改 `(abs(z)>1.5 || abs(y)>0.8)`。
- 必须用 `-c`（选区中心为原点），坐标才是格数。
- **坑**：`type=20` 这类"表达式里赋值"写法在本解析器不合法（赋值是语句不是表达式，报 `Couldn't find operator 'ass'`），所以用两条指令分开放。

### 5.6 全选区填充（替代 //set）

```
//g 1:0 1          把选区全部填成石头
//g -h 1:0 1       只填边界（空心箱体，等价 //faces）
```

### 5.8 环形管道（空心 + 管壁绝对封闭）

```
//pos1                          // 站在环心（或对准环心打点）
//outset 11                     // 外半径 = 8 + 2.5 = 10.5，11 够
//g -c 155:0 d=(sqrt(x^2+z^2)-8)^2+y^2; d>2.25&&d<6.25
```

> 长公式建议写成语句形式：`d=<公式>; <条件用 d>`——既缩短命令长度（1.7.10 聊天框
> 上限 100 字符，超长会被截断导致 Parser error），也让公式只写一遍。

- 截面为圆环：`r_in^2 < d^2 < r_out^2` 放方块，`d^2 < r_in^2` 留空 → 内部空心。
- 默认参数：通道直径 3 格（r_in=1.5，`2.25`=1.5²）、壁厚 1 格（r_out=2.5，`6.25`=2.5²）、
  环心半径 R=8（= 洞半径 5.5 + r_out）。
- 封闭性：截面是完整圆环，空腔任何格子的邻格都不是外部；管道环向闭合无端头 → 内外不连通。
- 带 X 轴玻璃窗版（玻璃是完整方块，不破坏封闭）——两条指令分开放：
  `//g -c 20:0 d=(sqrt(x^2+z^2)-8)^2+y^2; d>2.25&&d<6.25&&abs(z)<1.5`
  `//g -c 155:0 d=(sqrt(x^2+z^2)-8)^2+y^2; d>2.25&&d<6.25&&abs(z)>1.5`
- 通道直径 D / 壁厚 T：内半径平方=(D/2)²，外半径平方=((D/2)+T)²，R=5.5+(D/2)+T，选区外扩 > R+外半径。

### 5.9 预设：空心半球壳（穹顶屋顶）

球心 = 选区中心（`-c` 模式），半径 R=8 示例，壁厚 1：

```
//pos1                          // 站在球心（屋顶圆心）
//outset 8                      // 半宽 >= 半径
//g -c 155:0 d=x^2+y^2+z^2; d<64&&d>49&&y>0       // 上半球壳（凸穹顶）
//g -c 155:0 d=x^2+y^2+z^2; d<64&&d>49&&y<0       // 下半球壳（倒拱/天花板）
//g -c 155:0 d=x^2+y^2+z^2; d<64&&d>49            // 完整球壳
//g -c 155:0 d=(x/8)^2+(y/5)^2+(z/8)^2; d<1&&d>0.75&&y>0   // 扁穹顶（椭球）
```

- 半径 R：`64`=R²、`49`=(R-1)²（壁厚 1）；壁厚 T：`49` → (R-T)²。
- `y>0` 上半 / `y<0` 下半 / 去掉即完整球。
- 组合屋顶：穹顶 + 墙体 `//g -c 155:0 max(abs(x),abs(z))<8&&y<0&&y>-4`（或 //cyl）。

## 8. CraftScript 脚本（//cs，适合复杂结构）

脚本放 craftscripts/ 目录（服务器运行目录下，dev 环境即 run/craftscripts/），执行 //cs 文件名.js。

示例 spiral_tower.js（螺旋塔）：

```javascript
// 螺旋塔：以站位为底，每层旋转 15°，向上 24 层
var origin = context.origin;
var height = 24;
context.remember();
var x, y, z;
for (y = 0; y < height; y++) {
    var angle = y * 15 * Math.PI / 180;
    for (var i = 0; i < 4; i++) {
        var a = angle + i * Math.PI / 2;
        x = Math.floor(origin.getX() + Math.cos(a) * 3);
        z = Math.floor(origin.getZ() + Math.sin(a) * 3);
        context.setBlock(x, Math.floor(origin.getY()) + y, z, 155, 0); // 石英柱
    }
    // 每 6 层加一圈横梁
    if (y % 6 == 0) {
        for (var a2 = 0; a2 < 2 * Math.PI; a2 += 0.1) {
            x = Math.floor(origin.getX() + Math.cos(a2) * 3);
            z = Math.floor(origin.getZ() + Math.sin(a2) * 3);
            context.setBlock(x, Math.floor(origin.getY()) + y, z, 41, 0); // 金环
        }
    }
}
context.print("螺旋塔生成完毕");
```

> CraftScript API（WE 6.1 内核）：context.origin（站位点 Vector）、context.setBlock(x, y, z, id, data)、
> context.getBlock(x, y, z)、context.remember()（生成前快照，可 //undo）、context.print(msg)。

## 9. 常见坑

1. **^ 是乘方不是异或**——写 x^2 就是 x²。
2. 表达式里变量每次求值都重置，**跨方块状态用 megabuf/gmegabuf**。
3. 默认坐标是 -1..1：球体半径永远是 1，想控制实际大小请调选区长宽比或用 -r。
4. -h 的壳基于 6 邻居判断，一格厚的薄壳建议用 -h，厚壳手写 && dist>0.75 更可控。
5. 表达式出错（如除零）只会在游戏里报错行，先 //calc <表达式> 单独验证数学部分。
6. 大选区 + undo 会占大量内存，超大型生成前先 //clearhistory 或 //limit 设个上限。
7. **命令总长不能超过 100 字符**（1.7.10 聊天输入框硬限制），超长会被截断、报 Parser error
   （如 Unmatched opening bracket）。表达式太长时用语句压缩：`d=<公式>; <条件用 d>`。
