# 重演模式与事故

> 灵魂设计：**因为物理是真的，跟着历史操作，事故会自己发生**。不是脚本演出，而是玩家按照 1986 年的操作步骤操作，物理模型自然重现事故。

## 时间压缩

- 默认 ×16：整夜 12.5 模拟小时 ≈ 47 分钟真实时间
- 可调 ×1 / ×4 / ×16 / ×60（只推进模拟时钟与氙/温度积分）
- 事件日志按真实时间戳滚动，面板时钟同步显示 MSK 时刻

## 历史清单（简化 6 个里程碑）

| 真实时刻 | 事件 | 玩家操作 |
|---|---|---|
| 04-25 01:06 | 开始降功率（3200→目标 1000） | 调棒位 |
| 04-25 13:00 | 降到 ~1600 MWt | 降负荷 |
| **04-25 14:00** | **ECCS 断开**（试验规程要求） | 面板上关 ECCS 开关（跟随历史=关掉） |
| 04-26 00:28 | 基辅电网要求保持出力 | 功率卡住 → 氙毒加深 |
| ~01:00 | 功率跌到 ~30 MWt | 被迫抽棒至只剩 ~8 根等效（界面警告反应性裕度过低） |
| 01:23:40 | **按下 AZ-5** | 红色按钮 → 石墨端效应 → 尖峰 → 爆炸 |

（01:23:04 汽轮机惰走试验开始为可选项，冷却流量下降辅助触发）

## 结局分支

| 结局 | 触发方式 | 结果 |
|---|---|---|
| **历史重演** | 按历史操作走完 | 爆炸 → 事故序列 |
| **安全停堆** | 不断 ECCS / 不抽满棒 / 保持裕度 | AZ-5 正常急停；成就"比 1986 年的操作员做得更好" |
| 其他事故 | 冷却全断还不处理 | 另一种死法（缓慢熔毁） |

重演可重置。

## 事故后果

1. **爆炸**：掀飞顶盖（真实：1000 吨盖板），结构破坏 + 粒子 + 音效；范围限定反应堆本体 + 少量周边，不炸玩家基地
2. **石墨火**：持续火块 + 烟柱，纯视觉 + 辐射源，**30 分钟自灭**（不灭火，不管它）
3. **辐射场**：每个辐射源（瓦砾/石墨火/corium）一个球形范围，距离衰减；无防护进圈 → 分级辐射病（恶心 → 呕吐粒子 → 虚弱掉血 → 死亡）；GTNH Hazmat 减免；污染按真实同位素半衰期缓慢衰减（游戏时间尺度）
4. **corium 象脚**：堆底生成，极强辐射，无法直接采
5. **一步封堆**：用混凝土方块围住堆坑（复用结构校验）→ 辐射归零 → 可安全开采 corium → 终局材料（耐高温合金/中子源）
6. 纪念：4 号机组铭牌块；现实日期 4/26 时特殊提示/成就（顺手）
