## 2. 设计原则（保留自旧 README，数值口径按完稿统一）

1. **拟真适度**：物理机制全真（见完稿第二部分），砍掉与拟真无关的繁琐操作链（无多步化工、无两阶段石棺）。
2. **拟真蒸汽-电转换**：本体**不直接吐电**——堆芯将冷却剂煮沸为干蒸汽（内部逻辑，**不生成蒸汽流体/物品**），蒸汽流量驱动 **2 台巨型汽轮机（K-500-65/3000，各 500 MW(e)，并网后出力）** 才出电；汽水循环（分离器→汽轮机→冷凝器→除氧器→给水泵→堆芯）全部内聚在模拟器内。
3. 冷却水：吃蒸馏水，**消耗量 = 蒸汽产出量**（单回路）。
4. 氙毒时间：正常模式 **1:1 游戏时间**；重演模式按模拟时钟压缩。
5. 控制面板：**ModularUI2（MODUI2）HoloUI 世界全息面板**（PoC 已跑通：`/rbmkui`）。
6. 爆炸：按完稿 §10 事故场景触发，只毁反应堆本体 + 写维度辐射源，不炸周边地形。

## 2. 反应堆物理核心公式

### 2.1 反应性基础
```
kэф = 有效增殖系数
ρ = Δk / kэф = (kэф − 1) / kэф
临界: ρ = 0；次临界: ρ < 0；超临界: ρ > 0
```

### 2.2 缓发中子份额（关键门槛）
```
β ≈ 0.0064（初始装料）   [物理模型/第1部分教材]
βэф ≈ 0.006 = 0.6%       [构造教材 §4.1]
```
**运行规则**：功率调节只允许在正反应性小范围内进行：**ρ < βэф ≈ 0.006（0.6%）**。
当 ρ > βэф → **瞬发超临界**（prompt critical）：功率以亚秒级周期暴涨——事故的物理根源。

### 2.3 反应堆周期与功率（升功率主公式）
```
N(t) = N₀ · e^(t/T)
T（周期）= 功率增长 e 倍所需时间；T 与 ρ 成反比；临界 T = ∞
ln(I/I₀) = t/T   （电离室电流 ∝ 功率）
```
- 周期 ≤ 20±2 s → 触发 АЗС/АЗСР（周期保护）
- 周期表刻度：120 ~ 20 秒
- 可接受的功率变化速度要求：**T > 30 s**，此时 ρ 需比 β 小数倍

### 2.4 对数测量特性（УЗС.13 对数通道）
```
Uэк = U₀ − B · log₁₀(I/I₀)，I₀ = 10⁻¹¹ A
```

### 2.5 ЦВР-9 反应性计算器量程（8 档）
| 档 | 量程(βэф) |
|----|-----------|
| 1 | ±0.02 |
| 2 | ±0.05 |

## 3. 反应性效应组成（驱动模拟的核心）

总反应性 ρ = Σ（控制棒位置贡献 + 温度效应 + 功率效应 + 碘坑/钐毒化 + 燃耗）。

### 3.1 停堆所需反应性平衡（构造教材 §3.4）
最小 СУЗ 效率必须保证：从额定功率最大允许反应性后备 → **最大增殖系数状态（无碘坑、冷却）**，反应堆保持压灭且次临界度 ≥ **1%**。

| 效应 | 估算值 | 说明 |
|------|--------|------|
| Xe¹³⁵ 碘坑解除 | Δρ ≈ **2.98%** | 停堆后氙毒化消退释放的正反应性 |
| 石墨冷却 工作温度→280°C | Δρ_t = 5×10⁻⁵×(284−20) ≈ **2.64%** | 温度效应（构造教材公式） |
| 全堆冷却 280→20°C | （并入上式） | |
| 功率效应 | Δρ_w = 2.2×10⁻⁶×3200 ≈ **0.7%** | 功率系数 × 额定功率 |

**峰值出现在初始装料**：冷却效应大正值 + 功率系数最大 + 石墨冷却效应为零 → 总和 ≈ **6.3%**。

### 3.2 运行反应性后备
- 总后备中只有补偿「燃耗+渣化毒物+钐稳态毒化」部分被**不可逆消耗**；
- 其余 ρзап 用于功率运行（补偿氙毒化、负效应）；
- РБМК-1000 规程规定保持 **45–48 根 РР 棒**当量的反应性后备；
- 停堆后需用移动吸收体补偿释放的 ρзап（氙坑峰值后的正反应性回升——**复刻"碘坑事故"必做**）。

### 4.3 传热方式与两类危机（构造教材 §4.2）
1. **对流换热**（壁温<饱和温度）：α ∝ υ^0.8；ТК 内水流速限 **6–7 м/с**（更大→振动/侵蚀）。
2. **泡核沸腾**（壁温>饱和温度）：传热增强。
3. **第一类危机（膜态沸腾）**：q>qкр → 蒸汽膜包覆 → α 下降一个数量级以上 → 包壳熔化。裕度：Kз = W(т)доп/W(т)тек ≥ 1。РБМК 热流水平不足以触发。
4. **第二类危机（液膜蒸干）**：x > xгр → 环状液膜破裂 → 包壳过热。**x < xгр 是所有 ТК 的硬限制**；xгр 决定 ТК 产汽量与功率上限。上部卡匣装强化传热器可把 ТК 功率提高 1.5 倍（线功率 60→上限 80 кВт/м）。

停堆 → Xe¹³⁵ 先增后减：初期反应性下降（氙坑，功率"峡谷"，难以启动）→ 峰值后反应性回升（**正反应性窗口**）。若氙坑期间强行大剂量拔棒 → 补偿过剩正反应性 → 风险骤增。这是**切尔诺贝利事故核心机制，游戏必做**。

## 1. 点动力学方程组与周期

### 1.1 方程（[A] 标准多组点动力学）

```
dn/dt   = (ρ − β)/Λ · n + Σᵢ λᵢ·Cᵢ        （n = 中子密度 ∝ N，功率）
dCᵢ/dt  = βᵢ/Λ · n − λᵢ·Cᵢ              （i = 1..6，缓发中子先驱核）
ρ = Δk/k_eff = (k_eff − 1)/k_eff
```

- 倒时方程（in-hour，静止反应堆周期 T 的精确关系）：
  ```
  ρ = Λ/T + Σᵢ βᵢ/(1 + λᵢ·T)
  ```
  游戏中每 tick 由当前 ρ 反解 T（二分/牛顿法，T∈[−1000, 500] s 截断），然后 `N(t+dt) = N(t)·e^(dt/T)`。
- 单组有效缓发近似（调试/快速原型用）：`dC/dt = (β/Λ)·n − λ̄·C`，`λ̄ = β/Σᵢ(βᵢ/λᵢ) ≈ 0.078 s⁻¹`（对应的先驱核平均寿命 ≈12.8 s）。则
  ```
  ρ = Λ/T + β/(1 + λ̄·T)
  →  ρλ̄T² + (ρ − Λλ̄ − β)T − Λ = 0
  →  T = [ −(ρ−Λλ̄−β) + √((ρ−Λλ̄−β)² + 4ρλ̄Λ) ] / (2ρλ̄)     （ρ>0 时取正根）
  ```

### 1.2 RBMK 常数

| 参数 | 值 | 级别 | 备注 |
|------|-----|------|------|
| β（初始装料） | 0.0064 | [B] | ЧАЭС 培训教材原文确认 |
| β_eff（运行堆芯） | **0.006** | [B] | INIS《The value of delayed neutron effective fraction in RBMK core》(RN:25028972)：运行 RBMK 的 βeff = 0.006（STEPAN 计算，含冷/热态随燃耗曲线）；与规格书 §2.2 一致 |

### 1.3 数值积分建议（游戏友好）

- 不要每个 tick 解 ODE（dt=50 ms 时显式格式在 ρ 接近 β 时数值不稳）。
- 推荐：**按 "静止周期 + 指数增长"**：每 tick 重算 T(ρ)，`N *= exp(dt/T)`；再按需要叠加缓发先驱核的慢变化（氙/温度反馈都在秒级，点动力学跟踪 20 Hz 足够）。
- 次临界（ρ<0）时：用次临界倍增公式近似（见 1.4），避免 e^(dt/T) 除零。

### 1.4 次临界状态（停堆/启动段）

```
N = N_src / (1 − k_eff) = N_src/|ρ|    （源强 N_src 由 АЗС/ИСС 计数级给定）
```

- 停堆后 n 快速跌至源水平 × (1/|ρ|)；反应堆"深度次临界" → ρ ≤ −(0.01~0.02) 时功率表读数为源计数。
- 启动段（10⁻¹¹~10⁻⁷ Nном）由 ИСС.3М 裂变室计数（规格书 §10.1），此段不适用功率仪表线性刻度。

## 3. 空泡/蒸汽反应性系数

> **这是 RBMK 的灵魂，也是规格书最大的缺口**：全文只有定性"失水大正效应"，没有 `dρ/dx` 的数值——没有它，"TG 跳闸→流量丧失→空泡→功率暴涨"这条事故链就只能硬编码 if，而不是从物理涌现。

### 3.1 定义与符号

```
α_void = dρ/dα      （α = 空泡份额 void fraction，堆芯平均体积含汽率，0~1）
α_void,x = dρ/dx    （x = 质量含汽率 quality，0~1）—— 两种口径，数值相差一个数量级级别，实现时必须选定并全局一致
```

- **符号为正**（[B] 教材 §4.1 功率系数由"паровой коэффициент"主导；Штейнберг-Копчинский 附录原文：паровой коэффициент 是 RBMK 全功率系数的主导成分；INSAG-7 后对策报告："the void coefficient of reactivity is the dominant component of the power coefficient"）。
- **INSAG-7 权威数值表（已下载全文核验）**——空泡系数（每 1 % 空泡份额）：

  | 堆芯状态 | 空泡系数（Δk/k 每 1 % 空泡） | 出处 |
  |----------|------------------------------|------|
  | 新装料（fresh, 1.8 %） | **−1.3×10⁻⁴**（负） | INSAG-7 §2.1 |
  | 稳态换料（平衡） | **+(2.0…2.5)×10⁻⁴** | INSAG-7 §2.1 |
  | 设计保证区间 | −3.2×10⁻⁴ ~ **+9.6×10⁻⁴** | INSAG-7 附 I-3.2 |
  | 事故工况（ChNPP-4 平均假设） | ≈**+3×10⁻⁴（0.3 mk/%）**；仅芯轴区空化时 ~3 倍 ≈ **+0.9 mk/%** | Neutronics of Chernobyl（INIS 记录） |
  | 全堆失水（0→100 % 空化） | **−2β（新料）→ +(4…5)β（平衡）** | INSAG-7 §2.1 |
  | 1.8 % 富集度实测（随燃耗↑/AA↓） | −0.22βэф(211 AA) → **+5.1βэф**(32 AA) 列宁格勒-1；−0.16→+4.9βэф 切尔诺贝利-1；−0.38→+5.3βэф 切尔诺贝利-2 | INSAG-7 附 I-3.2 |
  | 事故前 ChNPP-4（燃耗 1100–1200 MW·d/t、ORM 26–30 棒、2 % 燃料） | 趋向 **+5βэф** 量级 | INSAG-7 附 I-3.2 |

- **游戏口径建议**：标准档用平衡值 `α_void = +(2.0…2.5)×10⁻⁴ Δk/k 每 1 % 空泡份额` × 轴向权重 w(z)（§3.2）；事故剧本（深插棒+高燃耗+低 ORM）可令 α_void 向 +5βэф≈+0.032 每单位空泡渐进——即可自然重现"功率低反而危险"的行为。
- 自洽性约束 [C]：规格书 §3.1 功率系数 −2.2×10⁻⁶/MW（满功率净 −0.7 %）为**净**效果（空泡正贡献 + 石墨正贡献 − 多普勒负贡献 相抵后为净负），因此 `满功率 Δρ_void = α_void·Δα_满功率` 必须 < 0.7 %，否则满功率稳态不成立。用平衡值 2×10⁻⁴ × Δα(≈14.5 %×0.65)≈1.9×10⁻⁴=0.019 % ✓ 远小于 0.7 %，自洽成立；事故态 +5βэф 是"异常状态"数值（低功率+深插棒+高燃耗），不与满功率稳态冲突。

### 3.2 轴向分布模型（[B] 教材 + [C] 建模）

- 沸腾沿通道高度发展：**空泡集中在堆芯上部**（出口 x=14.5 % 在上部达到）。
- 建议按层给权重：`α_void(z) = α_void,avg × w(z)`，w(z) 单调递增（底部 ~0.2、顶部 ~1.6，归一后平均 =1）[C]。
- 与"层重要度"（§6）耦合：上部空泡正反馈 × 上部中子重要度 → **深插棒把功率推向底部水区 + 空泡集中于上部 = 切尔诺贝利式灾难空间的成因**，游戏无需显式编程，只要这两条都进模型，行为会自动出现。

### 3.3 事故链模型（必做，[C]）

```
ГЦН 跳泵/断电 → 单回路流量 G↓（泵惰转 1–5 s 指数衰减）
→ 通道含汽率 x↑（Δh 不变时 x 反比于 G）→ 空泡份额 α↑
→ 正空泡反应性 Δρ_void = α_void·Δα > 0
→ 功率升 → 焓增↑ → x 进一步升 → 正反馈闭环
→ 若 α_void·Δx 超过操作员补偿速度 → 功率失控 → АЗС/АЗМ → 跳堆或事故
```

## 4. 温度反应性系数（石墨 + 多普勒）

### 4.1 石墨温度效应（[B] 教材修正版）

```
全堆冷却释放的正反应性： Δρ_t = 1×10⁻⁴ × (T_гр,рабоч − 20) ℃        （积分式，修正 E1）
  工作温度 ≈284 ℃ → 20 ℃ 时：Δρ_t = 1×10⁻⁴ × 264 = 2.64 %
```

- **方向（教材明确口径）**：冷态无氙是最大增殖状态，"расхолаживание графита... большой положительный"（冷却释放 +2.64 % 正反应性）⇒ 冷→热方向插入负反应性。建议实现：
  `ρ_graphite = −1×10⁻⁴ × (T_гр − 20) ℃`（冷→热为负、热→冷为正，积分恒 = 2.64 %）。
- **符号细节说明**：文献中石墨微分温度系数在工作温度附近符号存在温区依赖（教材原文公式 OCR 残缺——见勘误表 E1，无法判定其微分符号），游戏用上述一阶积分式即可满足所有验收行为；若未来拿到《Second part》原文再替换为分段微分表。
- 石墨温度 T_гр 的时间常数：**远慢于燃料**（石墨比热大，τ ~ 数分钟~小时），游戏中用一阶滞后（τ ≈ 600–3600 s）[C]。石墨温度 >750 ℃ 触发限制（规格书 §4.1）。

### 4.2 燃料多普勒效应（[B] 参照 + [A] 标准）

```
Δρ_Doppler = α_D × (T_fuel − T_fuel,ref)，α_D ≈ −(1…3)×10⁻⁵ 1/℃    [B: Springer 基准 −2.5×10⁻⁵/℃]
```

- 符号恒负（共振吸收展宽），**瞬时响应**（无滞后）。事故分析论文《Neutronics of the accident at Chernobyl》佐证："The Doppler effect is the only one introducing a negative feedback during the transient"——它是空泡正反馈回路里唯一的即时负抑制项。
- 燃料温度：燃料中心 ≤1600 ℃（实际限值，教材 §2.4），包壳 ≈300 ℃（规格书 §1.3）。温度场用简化径向分布：T_center ≈ T_coolant + (ΔT_radial)。
- 多普勒虽然小，但在空泡正反馈回路里是唯一的即时负抑制项——**必须进模型**，否则事故链单向失控过于简单。

### 4.3 组合（[C] 与规格书 §3.1 自洽）

```
ρ_total = ρ_rod + ρ_void(x) + ρ_graphite(T_гр) + ρ_doppler(T_fuel) + ρ_Xe + ρ_Sm + ρ_burnup
```

规格书 §3.1 的 6.3 % 拆解验证 [C]：Xe 2.98 % + 全堆冷却 2.64 % + 功率效应 0.7 % ≈ **6.32 % ≈ 6.3 % ✓** → 停堆后备需求 = 6.3 % + 次临界 1 % = **≥7.3 % ≈ 11.4 β**。

## 6. 功率形状因子模型

### 6.1 轴向形状（[B] 教材 + [C] 建模）

- 限制：K_z（高度不均匀系数）≤1.7；径向 K_ч ≤1.4（规格书 §4.1）。
- 建议模型：轴向功率包络 `P(z) = P_avg · f_ax(z)`，其中
  ```
  f_ax(z) = cos(π·(z − z_c)/H_eff) 形式 + 棒位修正 + 空泡修正
  ```
  - 棒位修正：吸收体所在高度功率压低（P(z) ∝ 1 − ρ_rod_layer(z) 的归一化）；
  - 空泡修正：上部空泡多 → 上部慢化差 → 功率略降（但空泡区水密度低 → 谱硬化）——取一阶：`f_ax(z) ∝ (1 − 0.5·x(z))`；
  - **深插棒 + 低功率**（切尔诺贝利初始态）：底部无水柱区域功率高、上部被棒压制 → 形状反转"下半区热"→ 这是事故物理链的触发器，必须能自然出现 [C]。
- 归一：∫f_ax dz = H_eff，保证总功率不变。

### 6.2 径向形状（[C] 简化）

- 径向包络用中心高-边缘低的函数（如余弦/贝塞尔近似），中心通道功率 ≈1.3×平均（保证 K_ч ≤1.4 校验通过）。
- 通道功率分配：`P_ch = P_total × f_rad(x,y) × f_ax(z) / Σ`——把 1661 通道映射到游戏通道（§9 粒度）。

### 6.3 每 tick 校验（迁移自规格书 §14.1）

```
P_ch,max ≤ 3 MW → 否则局部过热/危机
K_z ≤ 1.7、K_ч ≤ 1.4 → 超限触发 ЛАЗ/工艺保护
T_гр < 750 ℃（固定节点 440 ℃）
x < x_гр → 否则燃料损伤累计
W ≤ 3300 MW（设计持续限）
```

## 8. 自动调节器控制律

- СУЗ 是闭环随动系统（[B]：следящая, замкнутая）。
- 建议（[C] 设计，规格书 §7.1 范围/精度表为准）：

```
误差 e = N_зад − N_тек（规格书 §7.1 允许 ±1.5 %N / ±3 %N）
死区 δ = 精度值（±1.5 %N 或 ±3 %N）
|e| > δ：棒速 = k_P·e（限幅到最大功率变化速率 0.15 %N/s ↔ 对应棒速 0.4 m/s）
|e| ≤ δ：棒速 = 0
积分项可选（消除残留偏差，但积分速度 ≤ 0.075 %N/s 慢速档）
```

- АРМ（0.25–6 %N）与 1АР/2АР（5–100 %N）同一控制律、不同量程；ЛАР 分区（9–12 区）各配一路。
- 深插棒规则（[B] 教材）：АРМ 置于 УП 1±0.5 m（效率最大处），插 >3 m 后需回调——这是"操作员失误"的重要可玩源，控制律里应保留手动优先。
