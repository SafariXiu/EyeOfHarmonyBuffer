# 切尔诺贝利 RBMK 反应堆（EyeOfHarmonyBuffer）

> 2026 年，切尔诺贝利事件 40 周年纪念项目。在游戏里复刻一台 RBMK-1000 沸水堆：能发电、产放射性同位素、并完整重演 1986 年 4 月 26 日凌晨的事故。

## 定位

| 项目 | 值 |
|---|---|
| 科技等级 | UHV 左右 |
| 满功率出力 | ~e50（10^50 EU/s，挂无线电网，参考：戴森球完工 e200） |
| 结构规模 | 巨型多方块（总占地约 13×13×高 12） |
| 燃料体系 | 自定义（铀→燃料组件→乏燃料→同位素） |
| 核心玩法 | 拟真物理（正空泡系数 / 氙-135 中毒 / 控制棒石墨端效应）+ 历史时间线重演 |

## 设计原则（用户拍板）

1. **拟真适度**：保留事故体验与三个物理机制；砍掉所有需要玩家额外操作的繁琐过程（无硼砂灭火、无多步化工链、无两阶段石棺）。
2. 蒸汽**不接汽轮机**：本体直接吐 e50 电，蒸汽只作为内部参数显示。
3. 冷却水：吃蒸馏水，**消耗量 = 蒸汽产出量**（单回路）。
4. 正常模式氙中毒按 **1:1 游戏时间**（慢，真实）。
5. 控制面板：**ModularUI2（MODUI2）HoloUI 世界全息面板**（优先方案，PoC 先行）。
6. 爆炸只毁反应堆本体，不炸周边地形。
