# 结构与方块

## 整体布局

真实 RBMK-1000：1661 燃料通道 / 211 控制棒 / 堆芯 Φ11.8m×7m / 2488 柱石墨。游戏内按比例压缩：

```
俯视（堆芯 7×7 + 双层生物屏蔽 → 总占地 ~13×13）

  G G G G G G G G G      G = 石墨堆芯块（慢化，参与物理计算）
  G C C C C C C C G      C = 石墨/棒位（控制棒占位）
  G C F F F F F C G      F = 燃料通道块（插燃料组件）
  G C F F F F F C G
  G C F F F F F C G      B = 生物屏蔽块（混凝土+铅）
  G C F F F F F C G
  G C C C C C C C G
  G G G G G G G G G
  B B B B B B B B B

侧视（高约 12）：
  顶：控制棒驱动机构 + 汽水分离鼓 + 屏蔽盖
  中：堆芯 5 层（石墨 + 燃料通道 + 控制棒）
  底：重型混凝土底座 2 层
```

堆芯：7×7，其中燃料通道 25（5×5），控制棒位若干，其余石墨。25 通道满装燃料，燃耗按通道累计。

## 新方块清单（~14 种）

| 方块 | 职责 |
|---|---|
| 石墨堆芯块 | 结构主体；慢化（物理参与） |
| 燃料通道块 | 插燃料组件；GUI 看单通道燃耗 |
| 控制棒驱动块（顶） | 棒位视觉 + 插棒逻辑 |
| 汽水分离鼓（顶） | 蒸汽收集（真实 RBMK 标志外观） |
| 生物屏蔽块 | 混凝土+铅；事故前就防辐射 |
| 重型底座 | 地基 |
| 控制面板块 | 右键弹出全息面板（HoloUI） |
| AZ-5 按钮 | 红色实体按钮方块 |
| ECCS 隔离阀 | 重演模式关键开关（面板上开关，无需实体方块） |
| 冷却水口 | 蒸馏水输入 |
| 熔融堆芯块（corium） | 事故后堆底生成（象脚） |
| 石墨火块 | 事故后持续火（30 分钟自灭） |
| 污染瓦砾 | 辐射源（爆炸产物） |
| 4 号机组铭牌 | 纪念（顺手） |

## 结构校验

复用现有 `GTCM_MultiMachineBase` 的多方块结构校验逻辑（liquidFillCasing 那套），新增控制器与上述自定义方块。
