# 结构与方块

## 整体布局

真实 RBMK-1000：1661 燃料通道 / 211 控制棒 / 堆芯 Φ11.8m×7m / 2488 柱石墨。
游戏内：**堆芯定 8 层**（示意层，控制棒/燃料按 8 层对齐）；完整 1661/211 分布显示在**堆芯俯瞰屏**上（不要求实体结构做 47×47）。

## ⚠️ 搭建尺寸预留（务必看）

> 这是为了避免"搭好了发现控制棒顶到头 / 棒体没空间 / 结构校验不过"的**最小预留**。数值有富余，宁多勿少。

| 区域 | 建议高度 | 说明 |
|---|---|---|
| **堆芯本体** | **8 层**（Y0~Y7） | 燃料通道 + 控制棒通道 + 石墨，每层 1 格 |
| **堆芯上方预留** | **≥10 格**（推荐 12） | 控制棒**完全拔出**时吸收段（8 格）必须整个离开堆芯；再加驱动机构。**小于 8 格会顶穿** |
| **堆芯下方预留** | **≥2 格**（推荐 3） | 底座 + 控制棒底部空间 + 下部屏蔽 |
| **整个反应堆塔总高** | **约 20~23 格** | 底部 3 + 堆芯 8 + 顶部 12（含富余） |

**水平方向**：堆芯 7×7，外围反射层石墨一圈 + 生物屏蔽 2 层 → 总占地约 13×13。完整 1661 通道的密集分布**不需要**在实体里做（那是俯视屏显示的内容），实体只做示意规模。

**控制棒模型长度**：吸收段 8 格（对齐 8 层）+ 连接段 + 石墨置换段 ~4 格，整根比堆芯高。**完全拔出时整根棒体（含吸收段）移到堆芯上方储存区**——所以上方必须留够。

**校验约定**：结构校验（`screenCasing`/`glowCasing` 同款结构元素）会检查堆芯 8 层 + 上下预留区是否到位；区域不足 → 结构不成立、机器不工作。

## 新方块清单（~14 种）

| 方块 | 职责 |
|---|---|
| 石墨堆芯块 | 结构主体；慢化（物理参与） |
| 燃料通道块 | 插燃料组件；8 层；每通道一个 RodState |
| 控制棒通道块 | 8 层；含控制棒模型（材料分段）的移动空间 |
| 控制棒驱动块（顶） | 棒位视觉 + 插棒逻辑 |
| 汽水分离鼓（顶） | 蒸汽收集（真实 RBMK 标志外观） |
| 生物屏蔽块 | 混凝土+铅；事故前就防辐射 |
| 重型底座 | 地基 |
| 屏幕方块（3 屏） | 机器结构一部分：堆芯俯瞰 / 控制 / 参数（见 03-控制面板） |
| AZ-5 按钮 | 红色实体按钮方块 |
| ECCS 隔离阀 | 重演模式关键开关（面板上开关，无需实体方块） |
| 冷却水口 | 蒸馏水输入 |
| 熔融堆芯块（corium） | 事故后堆底生成（象脚） |
| 石墨火块 | 事故后持续火（30 分钟自灭） |
| 污染瓦砾 | 辐射源（爆炸产物） |
| 4 号机组铭牌 | 纪念（顺手） |

## 结构校验

复用现有 `GTCM_MultiMachineBase` 的多方块结构校验逻辑（liquidFillCasing / glowCasing 那套结构元素），新增：
- `screenCasing()`：收集屏幕方块坐标（面板位置）
- `controlRodCasing()` / `fuelCasing()`：收集 8 层通道，按通道建立 RodState
- 上下预留区高度检查（堆芯 + 储存空间不足则结构不成立）
