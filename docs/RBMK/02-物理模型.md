# 物理模型

> 每 tick 服务端推进；全部常数做成可调（集中在常量类）。核心是四个机制：正空泡系数、氙-135 中毒、控制棒石墨端效应、无安全壳（事故后果见重演模式文档）。
>
> **2026 升级**：控制棒从"单棒抽象（rodPos 0-100%）"升级为"每通道独立 RodState + 材料分段覆盖率"（详见第 6 节），石墨端效应由几何重叠自动产生，不再用条件特判。

## 1. 反应性合成

```
ρ = ρ_rods + ρ_xe + ρ_void + ρ_doppler

ρ_rods   : 所有控制棒通道覆盖率 × 分段反应性价值的叠加（见第 6 节，替代旧的"棒位 100%→+0.8$"线性映射）
ρ_xe     : −K_xe·(Xe − Xe_平衡)；满功率平衡约 −0.3$
ρ_void   : +C_v·voidFrac，C_v ≈ 0.022（真实 RBMK 空泡系数 ≈ +4.5β）
ρ_doppler: −k·max(0, T_fuel−600°C)（微弱负反馈，给玩家稳定点）
```

**单位 $：1$ = 1β（缓发中子份额）。ρ ≥ +1$ = 瞬发超临界 = 爆炸。**

## 2. 功率动力学

```
P *= exp(ρ·dt/τ)      τ ≈ 2~3 s（可调）
```

正反馈爬升来源：冷却不足 → 空泡↑ → ρ↑ → P 指数涨 → 更沸腾 → 失控。
正常范围由多普勒负反馈稳定。**ρ ≥ +1$ 直接判瞬发超临界 → 爆炸序列**（不做功率判定，简单干脆）。

## 3. 空泡份额

```
voidFrac = clamp(0.15·P + 0.45·(1−flowEff) + 0.2·max(0, P−0.85), 0, 0.6)
```

- 满功率正常运行 ≈ 18%
- 冷却中断 → 快速涨到 0.5+ → 正反馈 → 功率爬升（警告先行，给处理窗口）

## 4. 氙-135 / 碘-135（两仓模型，半衰期取真实值）

```
dI/dt  = 0.063·P − λ_I·I          λ_I  = 1/6.57 h
dXe/dt = λ_I·I − λ_Xe·Xe − BURN·P·Xe    λ_Xe = 1/9.14 h，BURN ≈ 0.5/h
```

- 满功率平衡氙毒 ≈ 0.3$；降到 30% 功率平衡毒涨到 ~0.7$ → 操作员必须抽棒补 → "碘坑"玩法
- 停堆后氙先涨后跌，峰值 ~10h → **刚停堆想重启？等着**
- 正常模式按 1:1 游戏时间；重演模式随模拟时钟 ×16

## 5. 温度

```
T_fuel += dt·(kf1·P − kf2·(T_fuel−T_coolant))   响应快（秒级）
T_graf += dt·(kg1·P − kg2·(T_graf−T_coolant))   响应慢（分钟级，石墨热容大）
```

燃料熔毁阈值 **2800°C**（真实 UO2 熔点 2865°C）。

## 6. 控制棒系统架构（每通道独立 + 材料分段）

> 参考设计讨论的结论：**一个逻辑对象 + 一个整体可移动模型**，模型内部分材料段；不生成大量普通实体。

### 6.1 每根棒独立状态（RodState）

俯视屏/燃料棒数据源 = 每根棒的 RodState。存于**反应堆主控制器**（不是模型实体），区块卸载/实体清除不丢状态：

```java
class RodState {
    long channelId;          // 通道（对应俯视屏一格）
    double logicalPosition;  // 连续位置（方块单位，0=堆芯底部）
    double targetPosition;   // 目标（正常移动 / AZ-5 目标）
    double movementSpeed;    // 驱动速度
    int rodType;             // 控制棒 / 缩短吸收棒(UA)
    boolean scram;           // 停堆插入中
    boolean jammed;          // 卡棒
    RodSegment[] segments;   // 材料分段
}
```

### 6.2 材料分段（几何自动产生石墨端效应）

不要整根棒同材质。1986 旧式 RBMK 控制棒分功能段：

```
┌──────────────┐
│ 驱动连接段    │  （中性）
├──────────────┤
│ 中子吸收段 ×8 │  反应性价值为负（−0.09/格 量级）
├──────────────┤
│ 水隙/连接区域 │  （中性）
├──────────────┤
│ 石墨置换段 ×4 │  反应性价值为**正**（+0.025/格，排开底部水→增强慢化）
└──────────────┘
```

每段保存 `localBottom` / `length` / `material` / `worth`。**位置改变时逐段×逐层算覆盖率**：

```
worldSegmentBottom = rod.logicalPosition + segment.localBottom
重叠长度 = max(0, min(段顶, 层顶) − max(段底, 层底))
coverage = clamp(重叠长度, 0, 1)        // 每层 1 格高
层反应性 += coverage × segment.worth × 局部通量权重
```

**石墨端效应由此自然浮现**：AZ-5 从全拔状态开始下插 → 石墨置换段**先**进入堆芯底部（吸收段还没到）→ 底部获得正反应性 → 尖峰 → 吸收段继续下插 → 负反应性主导。**不需要再写"棒位>90% && P<20% → +0.5$"的特判**；正常抽插棒同样正确反映石墨端。

### 6.3 连续位置 + 移动逻辑

- 位置用**连续方块单位**（`logicalPosition`），不用 0-7 整数（避免一格一格跳、反应性阶梯变化）。
- 显示层 0-100% 仅作换算：`positionBlocks = rodPos/100 × 层数`。
- 移动按速度逼近目标，AZ-5 也走速度（不是瞬间插到底）：

```
差 = target − logicalPosition
若 |差| ≤ maxMove  → 到位
否则               → logicalPosition += sign(差) × maxMove   // 下插需要时间
```

### 6.4 逻辑位置与渲染位置分离（同步）

```
服务端：logicalPosition 每 tick 推进 → 算覆盖率 → 反应性
客户端：renderPosition = lerp(renderPosition, logicalPosition, 0.25)   // 平滑追赶
```

**绝不用渲染坐标算物理**（卡顿/不同步/实体清除都会破坏反应堆逻辑）。

## 7. AZ-5 石墨端效应（几何机制版，重演灵魂）

由 6.2 的材料段重叠自动产生，不再条件特判：

```
按下 AZ-5 → 所有棒 target = 完全插入，按驱动速度下插（不是瞬移）
下插初期：石墨置换段先入堆底（吸收段未到）→ 底部正反应性
若此刻 反应性裕度极低（低功率 + 氙毒 + 全抽棒）→ 正反应性冲过 0 → 空泡正反馈 → 尖峰 → ≥1$ → 爆炸
正常状态 → 吸收段随后进入 → 负反应性主导 → 干净停堆
```

## 9. 代码架构（2026 定案）

控制棒系统**单独模块化**，机器类保持薄胶水，三块职责清晰：

```
rbmk/
├── physics/            ← 纯物理领域（不 import 机器/方块/TileEntity）
│   ├── RbmkRodSystem   ← 总控：所有通道的 RodState + 每 tick 驱动
│   ├── RodState        ← 单棒状态（position/target/speed/scram/jammed/segments）
│   ├── RodSegment      ← 材料分段（吸收/石墨置换/连接 + worth + 几何）
│   ├── RodPhysics      ← 覆盖率计算、移动逻辑、总反应性（纯函数，可单测）
│   └── RbmkCoreMap     ← 真实 1661/211 分布（现有 RbmkCoreData 挪入）
│
├── machine/            ← 机器集成（薄胶水）
│   └── EOHB_RBMK       ← 结构校验收集通道 → 喂给 RodSystem；每 tick 驱动；读功率
│
└── client/             ← 显示（现有 rbmk 包）
    └── 俯视屏 / 面板 / RbmkCoreData
```

**关键原则**：
1. physics 纯领域：只有 RodState/RodSegment/纯计算，不 import 机器/方块/TileEntity；可单测、可被机器/渲染/面板同时引用。
2. 机器类薄胶水：结构校验 `rodSystem.registerChannel(id, 类型, 坐标)`；每 tick `rodSystem.tick(dt, 参数)`；读 `rodSystem.getTotalReactivity()` / `getChannelState(id)`。
3. 参数集中：分段 worth、驱动速度、8 层高度放 physics 常量类。
4. 实例化而非全局单例：一台机器挂一个 `RbmkRodSystem`，NBT 存系统状态（支持多台机器）。
