# 燃料与同位素（自定义体系）

## 燃料链（3 步，砍掉化工中间步骤）

```
铀粉 → 燃料组件（合成台/组装机）→ 进堆燃烧（燃耗 MWd/tU）
→ 乏燃料 → 后处理机（PUREX 风格）→ 按真实双峰产额概率出同位素
```

- 燃料组件：自定义物品，含富集铀，锆包壳风格；25 通道按通道计燃耗
- 组件寿命 0 → 面板提示换料
- 乏燃料：~96% U 回收 + ~1% Pu + ~3% 裂变产物
