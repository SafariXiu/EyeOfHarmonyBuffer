# 控制面板（HoloUI 世界全息面板）

## 技术选型：ModularUI2（MODUI2）HoloUI

- 库：`com.github.GTNewHorizons:ModularUI2:2.3.79-1.7.10:dev`（包 `com.cleanroommc.modularui`）
- **HoloUI = 世界内可交互 UI**：`HoloUI.builder().at(x,y,z)` / `.inFrontOf(player, dist, fixed)` / `.faceToPlayer()` / `.faceTo(x,y,z)` / `.virtualScreenSize(w,h)` / `.screenScale(s)` → `.open(ModularScreen)`
- 底层 `HoloScreenEntity`（实体渲染），朝向 `ScreenOrientation.FIXED / TO_PLAYER`
- `HoloUI.registerSyncedHoloUI(ResourceLocation, Supplier<ModularScreen>)`：服务端可同步打开，多人可见
- ⚠️ 官方标注 `@ApiStatus.Experimental`（"Highly experimental"），且官方测试代码中该用法被注释（ScreenEntityRender 有 TODO）→ **必须先做 PoC 验证**：世界渲染、清晰度、交互、多人同步
- 降级方案：控制面板方块右键弹出全屏 MODUI2 面板（稳定成熟），视觉元素不变

## 控件映射（MODUI2 现成控件）

| 需求 | 控件 | 说明 |
|---|---|---|
| 棒位调节 | `SliderWidget` | `.bounds(0,100)` + `.stopper(0,25,50,75,100)` 五档卡位；`.value(IDoubleValue)` 双向绑定 |
| 状态数字 | `TextWidget` | `IKey.dynamic(Supplier<String>)` 每帧刷新；`.color()` 报警变色 |
| ECCS 开关 | `ToggleButtonWidget` | 布尔同步值 |
| AZ-5 | `ButtonWidget` | `Rectangle` 红色背景 + `child(TextWidget)` 大字；`.onMousePressed(mb->...)`；蜂鸣音 |
| 事件日志 | `Scrollable` | 滚动列表 |
| 报警闪烁 | `animation` 包 | Animator/ParallelAnimator |
| **功率曲线** | **`drawable/graph` 包** | `GraphDrawable`/`GraphView`/`Plot`/`GraphAxis`；重演模式叠加 1986 真实预置曲线 |

## 同步架构（物理全在服务端）

```
服务端每 tick 算物理 → ValueSyncHandler 家族
  (IIntSyncValue / IFloatSyncValue / IBoolSyncValue / EnumSyncValue / DynamicSyncHandler)
  → 状态快照 → 客户端面板显示
玩家操作（滑块/按钮）→ InteractionSyncHandler → 服务端生效
```

客户端面板只读快照，防作弊天然成立。

## 交互规则

- 棒位滑块：点击 → 服务端更新 rodTarget，棒按 ~5%/s 移动（真实驱动机构就是慢的）
- AZ-5：按下 → SCRAM 状态 → 红色闪烁 + 蜂鸣 → 服务端走石墨端判定
- 模式切换：正常运行 / 重演模式 / 重置重演（枚举同步值）
- 时钟倍率：×1 / ×4 / ×16 / ×60（只推进模拟时钟和氙/温度积分）
- 换料：组件寿命到 0 提示，面板一键换新（服务端物品操作）
