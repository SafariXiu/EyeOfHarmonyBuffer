# 控制面板（自写世界 UI · 三屏规格）

> 自写世界全息/方块渲染（不再用 ModularUI2 的 HoloUI，官方 experimental 且 Angelica 下不可用）。
> 渲染：TileEntity + TESR；控件系统：RbmkHoloControl（z-order/hover/点击）；交互：准星拾取 + LOS + 距离 + 激活门控。

## 屏幕方块

- 一个自定义 **Block + TileEntity**（普通方块结构件，不是 GT hatch），作为机器结构的一部分（用结构元素 `screenCasing()` 收集坐标到 `mScreenBlocks`，机制同 `glowCasing`/`liquidFillCasing`）。
- **页面 ID**：方块 meta 或 TileEntity NBT 区分（0 = 堆芯俯视 / 1 = 控制 / 2 = 参数）。
- 朝向：结构收集时记录方块朝外方向，面板法向固定朝外。
- 面板渲染位置 = 方块 pos + 朝外方向 × 0.05 格（"靠方块无限近、看不出不挨着"）。

## 交互基础（三屏共用）

- 准星射线命中面板平面 → 局部坐标 (u,v)。
- **交互距离** `MAX_INTERACT_DIST = 8`（超了不响应）。
- **视线遮挡**：玩家到面板路径上任何非空气方块（含玻璃/栅栏）都算挡，不可交互。
- **激活门控**：左键点面板激活后才响应控件；右键退出（返回上层/关闭）。
- **数据源（确认）**：机器 controller 服务端 `onPostTick` 打包物理状态广播给 client，屏幕只读快照；玩家操作（滑块/AZ-5/输入）经 client → 服务端 → controller 生效。

## 屏幕 0：堆芯俯瞰图（大俯视图）

**用途**：显示整个堆芯的控制棒/石墨棒俯视布局，光标（准星）指向查看每根燃料棒数据。

**虚拟分辨率**：640 × 480（放大显示，格子清晰）

**布局**（堆芯 5x5 = 25 通道 + 石墨/棒位，格子间带间距）：

```
┌──────────────────────────────────────────────┐
│  堆芯俯瞰 · 25 通道       (准星指向查看)      │
├──────────────────────────────────────────────┤
│   ┌─┬─┬─┬─┬─┐                                │
│   │F│F│F│F│F│   F = 燃料通道色块              │
│   │F│F│F│F│F│       （颜色 = 温度/棒位）       │
│   │F│F│F│F│F│   G = 石墨占位                  │
│   │F│F│F│F│F│   R = 控制棒占位               │
│   │F│F│F│F│F│                                │
│   └─┴─┴─┴─┴─┘                                │
│                                              │
│  ▶ 通道 #12  棒位 62%  温度 980°C  燃耗 12.4  │ ← hover 详情
└──────────────────────────────────────────────┘
```

**数据**（每通道）：棒位 %、温度 °C、燃耗 MWd/tU、状态（正常/偏热/熔毁警告）
**格色**：温度从蓝（冷）→ 绿（正常）→ 橙（热）→ 红（超阈值）
**交互**：准星指向某格 → 该格高亮 + 底部/侧边显示该通道详情；点击可选中（后续可联动控制屏）
**控件**：纯显示 + hover 高亮（z-order/hover 机制）

## 屏幕 1：控制屏

**用途**：调整燃料棒深度 + 关键按钮。

**虚拟分辨率**：480 × 270

**布局**：

```
┌────────────────────────────────────────────┐
│  控制台                                       │
│  控制棒深度 ▓▓▓▓▓░░░░░ 62%   [手动][ 62 ]   │ 滑块+输入框
│  ┌──────────────┐   ┌────────────┐          │
│  │   A Z - 5    │   │ ECCS 断开  │          │ AZ-5 + ECCS
│  └──────────────┘   └────────────┘          │
│  [模式:运行] [时钟:×1]                       │ 模式/时钟
└────────────────────────────────────────────┘
```

**控件**：
- 控制棒深度滑块（点击轨道设值）+ 输入框（MC 原生 GuiTextField，0-100 业务校验）
- AZ-5 紧急停堆按钮（红，点击切换）
- ECCS 隔离阀开关（ToggleButton）
- 模式切换（运行/重演）、时钟倍率（×1/×4/×16/×60）——CycleButton

**交互**：准星点击 / 输入框弹 MC 原生输入 GUI

## 屏幕 2：参数屏

**用途**：显示 README 里那一大堆参数（状态读数 + 仪表条）。

**虚拟分辨率**：480 × 270

**布局**：

```
┌────────────────────────────────────────────┐
│  RBMK-1000 · 堆芯参数                         │
├─────────────────┬──────────────────────────┤
│ 热功率   83%    │ 空泡份   18%  ▓░          │
│ 电功率  e50.9   │ 氙-135 0.7$  ▓▓░          │
│ 石墨温度 340°C  │ 反应性 +0.31$ (14 棒)     │
│ 燃料温度 980°C  │ 蒸汽   1210 L/s           │
│ 冷却水   ✓     │ 燃耗  12400 MWd/tU        │
│ 蒸汽压力 7.0MPa │ 组件寿命 ▓▓▓▓░░ 78%       │
└─────────────────┴──────────────────────────┘
```

**数据**（对照 `02-物理模型.md`）：
| 项 | 说明 |
|---|---|
| 热功率 % | 超 100% 变红 |
| 电功率 | e50 口径（e# 格式化） |
| 石墨/燃料温度 | 燃料 >2800 熔毁红色 |
| 空泡份 % | 仪表条，爬升警告 |
| 氙-135 | 反应性亏损，仪表条 |
| 反应性 ρ/$ + 等效棒数 | <15 报警报红 |
| 蒸汽流量/压力、冷却水 | 只读 |
| 燃耗/组件寿命 | 仪表条 |

**交互**：纯显示；超阈值仪表条/数值变红（报警闪烁可后加）

## 材质方向（供你画方块材质）

- **一个屏幕方块**，三个页面用 meta/NBT 区分（材质可统一或微区别）。
- 建议外观：黑色屏幕面 + 深灰边框（发光外壳风格），程序绘制的内容（TESR）画在屏幕面上方，方块本体贴图是"屏幕底座/边框"或纯黑屏。
- 尺寸：1×1 方块承载一个大悬浮面板（虚拟屏放大到方块前空间）。
